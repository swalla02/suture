# Suture language v0, plan 2 of 5: prototype slice 1 (conditional depth) — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working prototype. `suture run examples/shop --scenario …` compiles `shop.st` and `france.st` and runs a French order and a Japanese order end to end against simulated services. It prints a trace of every step, and `suture explain` says why a unit is waiting.

**Architecture:**
- **`suture-lang`** parses `.st` files (statements, then controlled-English sentences), checks them, and emits a compiled program (data) with a read-back for every rule.
- **`suture-runtime`** runs that program on the existing kernel.
  - Each root entity, with everything it owns, is one unit: one kernel agent with a mailbox.
  - One generic kernel rule interprets the program for every message.
  - Outside requests are kernel effects, which a host loop routes, commits and dispatches to simulated adapters.
- **`suture-cli`** wraps both in the `suture` command.

**Tech stack:** Rust (edition 2024, rust-version 1.85). Dependencies are limited to `serde`, `serde_json`, `thiserror` and the `suture` kernel.

**Spec:** `docs/superpowers/specs/2026-10-14-suture-language-design.md`. Appendix B is binding for this plan (scope B.2, semantics B.3, acceptance B.4). Sections 3 and 5 give the wider design that B narrows.

## Global Constraints

- **Language subset and semantics:** exactly spec Appendix B.2 and B.3. Anything listed under "waits for slice 2" is out of scope.
- **Crates:**
  - `lang/` (`suture-lang`);
  - `runtime/` (`suture-runtime`);
  - `cli/` (`suture-cli`, which builds the binary `suture`).

  The root `Cargo.toml` becomes their workspace. No dependencies beyond `serde`, `serde_json`, `thiserror` and the kernel.
- **Units fit the kernel's payload limit of 4096 bytes.** A step whose unit would exceed it faults, and the host reports the fault.
- **Host loop order:** run → take new effects → route internal messages → commit → dispatch outside requests (B.3.6).
- **Determinism:** the same program and scenario always give the same trace and the same journal digest.
- **Commands:** run tests with `cargo test --release --workspace`. Lints: `cargo clippy --release --workspace --all-targets -- -D warnings` stays clean.
- **Branch:** `lang-slice-1`. Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **The example `.st` files contain no control flow** (spec §1.1).

## Review Focus

1. **A late or duplicate answer** must leave the unit unchanged and add a note. Examples: an adapter answering a request twice, or answering for a part that was withdrawn. It must never crash or apply twice. Test in Task 6: `a_late_answer_is_ignored`.
2. **An answer whose data has the wrong type,** such as `value "abc"` for a `Money` attribute, is refused with a clear note, and the request goes out again. Test in Task 6: `wrongly_typed_answer_data_is_refused`.
3. **A unit that outgrows the payload limit** is reported as a fault by the host, never a panic. Test in Task 7: `an_oversized_unit_is_reported_not_panicked`.
4. **Ambiguous names:** a defined state with the same name as an attribute, or a part kind owned by two kinds, is a compile error with file and line. Test in Task 4: `ambiguous_names_are_errors`.
5. **A scenario step that can't apply** must make the report fail with a message, never a panic. Examples: an answer with no pending request, or an expectation about a unit that doesn't exist. Test in Task 8: `impossible_scenario_steps_fail_the_report`.

```rust
//! Source text to statements, statements to tokens, and a cursor that the
//! parsers share.
//!
//! A statement starts on a line with no indentation. The indented lines
//! that follow are its continuation lines. `--` starts a comment that runs
//! to the end of the line, except inside a string.

use std::fmt;

/// An error with the file and line it comes from.
#[derive(Clone, Debug, PartialEq, Eq, thiserror::Error)]
#[error("{file}:{line}: {msg}")]
pub struct Error {
    pub file: String,
    pub line: usize,
    pub msg: String,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Tok {
    Word(String),
    Str(String),
    Num(String),
    /// The possessive `'s`.
    Poss,
    Sym(char),
}

impl fmt::Display for Tok {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            Tok::Word(w) | Tok::Num(w) => write!(f, "{w}"),
            Tok::Str(s) => write!(f, "\"{s}\""),
            Tok::Poss => write!(f, "'s"),
            Tok::Sym(c) => write!(f, "{c}"),
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Stmt {
    pub file: String,
    pub line: usize,
    /// The first line's tokens, then each continuation line's.
    pub lines: Vec<Vec<Tok>>,
}

impl Stmt {
    /// All tokens, continuation lines included.
    pub fn tokens(&self) -> Vec<Tok> {
        self.lines.concat()
    }

    pub fn error(&self, msg: impl Into<String>) -> Error {
        Error { file: self.file.clone(), line: self.line, msg: msg.into() }
    }
}

pub fn statements(file: &str, src: &str) -> Result<Vec<Stmt>, Error> {
    let mut out: Vec<Stmt> = Vec::new();
    for (i, raw) in src.lines().enumerate() {
        let line = i + 1;
        let text = strip_comment(raw);
        if text.trim().is_empty() {
            continue;
        }
        let toks = tokens(text).map_err(|msg| Error { file: file.to_string(), line, msg })?;
        let indented = text.starts_with(' ') || text.starts_with('\t');
        match out.last_mut() {
            Some(s) if indented => s.lines.push(toks),
            None if indented => {
                return Err(Error { file: file.to_string(), line, msg: "indented line outside a statement".into() });
            }
            _ => out.push(Stmt { file: file.to_string(), line, lines: vec![toks] }),
        }
    }
    Ok(out)
}

/// The line without its `--` comment. A `--` inside a string is kept.
fn strip_comment(line: &str) -> &str {
    let bytes = line.as_bytes();
    let mut in_str = false;
    for (i, b) in bytes.iter().enumerate() {
        match b {
            b'"' => in_str = !in_str,
            b'-' if !in_str && bytes.get(i + 1) == Some(&b'-') => return &line[..i],
            _ => {}
        }
    }
    line
}

/// Splits one line into tokens.
pub fn tokens(text: &str) -> Result<Vec<Tok>, String> {
    let chars: Vec<char> = text.chars().collect();
    let mut out = Vec::new();
    let mut i = 0;
    while i < chars.len() {
        let c = chars[i];
        if c.is_whitespace() {
            i += 1;
        } else if c == '"' {
            let start = i + 1;
            let mut j = start;
            while j < chars.len() && chars[j] != '"' {
                j += 1;
            }
            if j == chars.len() {
                return Err("unterminated string".into());
            }
            out.push(Tok::Str(chars[start..j].iter().collect()));
            i = j + 1;
        } else if c.is_ascii_digit() {
            let start = i;
            while i < chars.len() && (chars[i].is_ascii_digit() || chars[i] == '.') {
                i += 1;
            }
            out.push(Tok::Num(chars[start..i].iter().collect()));
        } else if c.is_alphabetic() || c == '_' {
            let start = i;
            while i < chars.len() && (chars[i].is_alphanumeric() || chars[i] == '_') {
                i += 1;
            }
            out.push(Tok::Word(chars[start..i].iter().collect()));
            let possessive = chars.get(i) == Some(&'\'')
                && chars.get(i + 1) == Some(&'s')
                && !chars.get(i + 2).is_some_and(|d| d.is_alphanumeric());
            if possessive {
                out.push(Tok::Poss);
                i += 2;
            }
        } else if "{}:,=|()".contains(c) {
            out.push(Tok::Sym(c));
            i += 1;
        } else {
            return Err(format!("unexpected character {c:?}"));
        }
    }
    Ok(out)
}

/// A position in a statement's tokens, with the helpers the parsers share.
pub struct Cursor<'a> {
    toks: &'a [Tok],
    pos: usize,
    file: &'a str,
    line: usize,
}

impl<'a> Cursor<'a> {
    pub fn new(toks: &'a [Tok], file: &'a str, line: usize) -> Self {
        Cursor { toks, pos: 0, file, line }
    }

    pub fn error(&self, msg: impl Into<String>) -> Error {
        Error { file: self.file.to_string(), line: self.line, msg: msg.into() }
    }

    pub fn peek(&self) -> Option<&'a Tok> {
        self.toks.get(self.pos)
    }

    pub fn peek_at(&self, k: usize) -> Option<&'a Tok> {
        self.toks.get(self.pos + k)
    }

    pub fn next(&mut self) -> Option<&'a Tok> {
        let t = self.toks.get(self.pos);
        if t.is_some() {
            self.pos += 1;
        }
        t
    }

    pub fn at_end(&self) -> bool {
        self.pos >= self.toks.len()
    }

    /// True if the next token is the word `w`.
    pub fn is_word(&self, w: &str) -> bool {
        matches!(self.peek(), Some(Tok::Word(x)) if x == w)
    }

    /// Consumes the word `w` if it is next.
    pub fn eat_word(&mut self, w: &str) -> bool {
        let found = self.is_word(w);
        if found {
            self.pos += 1;
        }
        found
    }

    pub fn expect_word(&mut self, w: &str) -> Result<(), Error> {
        if self.eat_word(w) { Ok(()) } else { Err(self.error(format!("expected `{w}`, found {}", self.found()))) }
    }

    pub fn eat_sym(&mut self, c: char) -> bool {
        let found = matches!(self.peek(), Some(Tok::Sym(x)) if *x == c);
        if found {
            self.pos += 1;
        }
        found
    }

    pub fn expect_sym(&mut self, c: char) -> Result<(), Error> {
        if self.eat_sym(c) { Ok(()) } else { Err(self.error(format!("expected `{c}`, found {}", self.found()))) }
    }

    pub fn eat_poss(&mut self) -> bool {
        let found = matches!(self.peek(), Some(Tok::Poss));
        if found {
            self.pos += 1;
        }
        found
    }

    /// Consumes and returns the next word.
    pub fn word(&mut self) -> Result<String, Error> {
        match self.peek() {
            Some(Tok::Word(w)) => {
                self.pos += 1;
                Ok(w.clone())
            }
            _ => Err(self.error(format!("expected a word, found {}", self.found()))),
        }
    }

    /// Consumes and returns the next word, which must start with a capital letter.
    pub fn kind_name(&mut self) -> Result<String, Error> {
        match self.peek() {
            Some(Tok::Word(w)) if w.starts_with(char::is_uppercase) => {
                self.pos += 1;
                Ok(w.clone())
            }
            _ => Err(self.error(format!("expected a kind name, found {}", self.found()))),
        }
    }

    pub fn expect_end(&self) -> Result<(), Error> {
        if self.at_end() { Ok(()) } else { Err(self.error(format!("unexpected {} at the end", self.found()))) }
    }

    /// The next token, for error messages.
    pub fn found(&self) -> String {
        self.peek().map_or_else(|| "the end of the statement".to_string(), |t| format!("`{t}`"))
    }
}
```

```rust
//! Unresolved syntax: what the parsers produce and the checker resolves.
//! Names are kept as written; the checker resolves them (spec B.3.8).

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Loc {
    pub file: String,
    pub line: usize,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum TypeName {
    Text,
    Bool,
    Money,
    Count,
    /// A reference to another kind; in slice 1, only to a part's owner.
    Kind(String),
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Literal {
    Text(String),
    Bool(bool),
    Money { cents: i64, currency: String },
    Count(i64),
}

/// `it`, `its x`, `the Order`, `the order's total`, `its form's order's total`.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct NounPhrase {
    pub head: Head,
    /// The words after the head: `its form's order's total` gives [form, order, total].
    pub steps: Vec<String>,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Head {
    /// `it`, `its`, `their`, or `the` followed by a lower-case word: the subject.
    It,
    /// `the Order`: the subject if it is an Order, otherwise its owner of that kind.
    The(String),
}

/// What follows `is`: a literal, a noun phrase, or a bare word that the
/// checker reads as text or as a state (spec B.3.7).
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Term {
    Lit(Literal),
    Np(NounPhrase),
    Word(String),
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum CmpOp {
    AtMost,
    AtLeast,
    MoreThan,
    LessThan,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Cond {
    /// `x is y`, `x is not y`
    Is { left: NounPhrase, negated: bool, right: Term },
    /// `x is at most y`, `x is at least y`, `x is more than y`, `x is less than y`
    Cmp { left: NounPhrase, op: CmpOp, right: Term },
    /// `x has a K [that is s]`, `x has no K [that is s]`
    Has { owner: NounPhrase, negated: bool, kind: String, state: Option<String> },
    And(Vec<Cond>),
    Or(Vec<Cond>),
}

/// `[state] Kind [whose attr is v] [that cond]`. Every filter is about the subject.
#[derive(Clone, Debug, PartialEq, Eq)]

    pub filter: Vec<Cond>,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum RuleBody {
    /// `every S's attr …`, `every S is …`: the condition holds for each subject.
    Every { subject: Subject, cond: Cond },
    /// `no S has … [unless c]`: the predicate holds for no subject, unless `c` does.
    No { subject: Subject, pred: Cond, unless: Option<Cond> },
}
```

```rust
//! The controlled-English sentence parsers (spec §3.3 and appendix B.2).
//! Each pattern has exactly one meaning; the checker resolves the names.

use crate::ast::*;
use crate::lex::{Cursor, Error, Tok};

/// A literal, if one is next: `"text"`, `3`, `120 EUR`, `12.50 EUR`, `yes`, `no`.
pub fn literal(c: &mut Cursor) -> Result<Option<Literal>, Error> {
    match c.peek() {
        Some(Tok::Str(s)) => {
            let s = s.clone();
            c.next();
            Ok(Some(Literal::Text(s)))
        }
        Some(Tok::Num(n)) => {
            let n = n.clone();
            c.next();
            let currency = match c.peek() {
                Some(Tok::Word(w)) if w.len() == 3 && w.chars().all(|ch| ch.is_ascii_uppercase()) => Some(w.clone()),
                _ => None,
            };
            match currency {
                Some(currency) => {
                    c.next();
                    let cents = money(&n).map_err(|m| c.error(m))?;
                    Ok(Some(Literal::Money { cents, currency }))
                }
                None => n
                    .parse::<i64>()
                    .map(|v| Some(Literal::Count(v)))
                    .map_err(|_| c.error(format!("`{n}` is not a whole number"))),
            }
        }
        Some(Tok::Word(w)) if w == "yes" || w == "true" => {
            c.next();
            Ok(Some(Literal::Bool(true)))
        }
        Some(Tok::Word(w)) if w == "no" || w == "false" => {
            c.next();
            Ok(Some(Literal::Bool(false)))
        }
        _ => Ok(None),
    }
}

/// An amount in cents: at most two decimals.
fn money(n: &str) -> Result<i64, String> {
    let bad = || format!("`{n}` is not an amount with at most two decimals");
    let (whole, frac) = n.split_once('.').unwrap_or((n, ""));
    if whole.is_empty() || frac.len() > 2 || frac.contains('.') {
        return Err(bad());
    }
    let w: i64 = whole.parse().map_err(|_| bad())?;
    let f: i64 = if frac.is_empty() { 0 } else { format!("{frac:0<2}").parse().map_err(|_| bad())? };
    Ok(w * 100 + f)
}

pub fn starts_noun_phrase(c: &Cursor) -> bool {
    ["it", "its", "their", "the"].iter().any(|w| c.is_word(w))
}

/// `it`, `its x`, `their x`, `the Kind`, `the x`, followed by any number of `'s y`.
pub fn noun_phrase(c: &mut Cursor) -> Result<NounPhrase, Error> {
    let mut np = if c.eat_word("it") {
        NounPhrase { head: Head::It, steps: vec![] }
    } else if c.eat_word("its") || c.eat_word("their") {
        NounPhrase { head: Head::It, steps: vec![c.word()?] }
    } else if c.eat_word("the") {
        let w = c.word()?;
        if w.starts_with(char::is_uppercase) {
            NounPhrase { head: Head::The(w), steps: vec![] }
        } else {
            NounPhrase { head: Head::It, steps: vec![w] }
        }
    } else {
        return Err(c.error(format!("expected `it`, `its` or `the`, found {}", c.found())));
    };
    while c.eat_poss() {
        np.steps.push(c.word()?);
    }
    Ok(np)
}

fn it() -> NounPhrase {
    NounPhrase { head: Head::It, steps: vec![] }
}

/// What follows `is` or `is not`.
fn term(c: &mut Cursor) -> Result<Term, Error> {
    if let Some(l) = literal(c)? {
        return Ok(Term::Lit(l));
    }
    if starts_noun_phrase(c) {
        return Ok(Term::Np(noun_phrase(c)?));
    }
    Ok(Term::Word(c.word()?))
}

/// What follows a noun phrase: `is [not] t`, `is at most t` and the other
/// comparisons, `has a K [that is s]`, or `has no K [that is s]`.
pub fn predicate(c: &mut Cursor, left: NounPhrase) -> Result<Cond, Error> {
    if c.eat_word("has") {
        let negated = if c.eat_word("no") {
            true
        } else if c.eat_word("a") || c.eat_word("an") {
            false
        } else {
            return Err(c.error(format!("expected `a`, `an` or `no` after `has`, found {}", c.found())));
        };
        let kind = c.kind_name()?;
        let state = if c.eat_word("that") {
            c.expect_word("is")?;
            Some(c.word()?)
        } else {
            None
        };
        return Ok(Cond::Has { owner: left, negated, kind, state });
    }
    c.expect_word("is")?;
    let op = if c.eat_word("at") {
        if c.eat_word("most") {
            Some(CmpOp::AtMost)
        } else {
            c.expect_word("least")?;
            Some(CmpOp::AtLeast)
        }
    } else if c.eat_word("more") {
        c.expect_word("than")?;
        Some(CmpOp::MoreThan)
    } else if c.eat_word("less") {
        c.expect_word("than")?;
        Some(CmpOp::LessThan)
    } else {
        None
    };
    if let Some(op) = op {
        return Ok(Cond::Cmp { left, op, right: term(c)? });
    }
    let negated = c.eat_word("not");
    Ok(Cond::Is { left, negated, right: term(c)? })
}

/// One condition. One that starts with `is` or `has` is about the subject.
fn simple(c: &mut Cursor) -> Result<Cond, Error> {
    let left = if c.is_word("is") || c.is_word("has") { it() } else { noun_phrase(c)? };
    predicate(c, left)
}

/// Conditions joined by `and` or by `or`; one sentence cannot mix the two.
/// After a joiner, a bare state shares the previous condition's left side:
/// `it is cancelled and paid and not refunded`.
pub fn condition(c: &mut Cursor) -> Result<Cond, Error> {
    let first = simple(c)?;
    let joiner = match c.peek() {
        Some(Tok::Word(w)) if w == "and" || w == "or" => w.clone(),
        _ => return Ok(first),
    };
    let mut parts = vec![first];
    while c.eat_word(&joiner) {
        let next = if c.is_word("is") || c.is_word("has") || starts_noun_phrase(c) {
            simple(c)?
        } else {
            let Some(Cond::Is { left, .. }) = parts.last() else {
                return Err(c.error(format!("expected a condition after `{joiner}`, found {}", c.found())));
            };
            let left = left.clone();
            let negated = c.eat_word("not");
            Cond::Is { left, negated, right: Term::Word(c.word()?) }
        };
        parts.push(next);
    }
    if c.is_word("and") || c.is_word("or") {
        return Err(c.error("one sentence cannot mix `and` with `or`; name a part with `define`"));
    }
    Ok(if joiner == "and" { Cond::And(parts) } else { Cond::Or(parts) })
}

/// `[state] Kind [whose attr is [not] t] [that cond]`.
pub fn subject(c: &mut Cursor) -> Result<Subject, Error> {
    let adjective = match c.peek() {
        Some(Tok::Word(w)) if !w.starts_with(char::is_uppercase) => {
            let w = w.clone();
            c.next();
            Some(w)
        }
        _ => None,
    };
    let kind = c.kind_name()?;
    let mut filter = vec![];
    if let Some(state) = adjective {
        filter.push(Cond::Is { left: it(), negated: false, right: Term::Word(state) });
    }
    if c.eat_word("whose") {
        let attr = c.word()?;
        c.expect_word("is")?;
        let negated = c.eat_word("not");
        filter.push(Cond::Is { left: NounPhrase { head: Head::It, steps: vec![attr] }, negated, right: term(c)? });
    }
    if c.eat_word("that") {
        filter.push(condition(c)?);
    }
    Ok(Subject { kind, filter })
}

/// `every S's attr …`, `every S is …`, `no S has … [unless cond]`, `no S is … [unless cond]`.
pub fn rule_body(c: &mut Cursor) -> Result<RuleBody, Error> {
    if c.eat_word("every") {
        let subject = subject(c)?;
        let mut left = it();
        while c.eat_poss() {
            left.steps.push(c.word()?);
        }
        let cond = predicate(c, left)?;
        return Ok(RuleBody::Every { subject, cond });
    }
    if !c.eat_word("no") {
        return Err(c.error(format!("a rule starts with `every` or `no`, found {}", c.found())));
    }
    let subject = subject(c)?;
    let pred = predicate(c, it())?;
    let unless = if c.eat_word("unless") { Some(condition(c)?) } else { None };
    Ok(RuleBody::No { subject, pred, unless })
}
```

```rust
//! Statement parsers (spec §3.2 and appendix B.2). The first word says which
//! statement it is; a capitalized first word starts `Kind needs …`.

use crate::ast::*;
use crate::lex::{statements, Cursor, Error, Stmt, Tok};
use crate::sentence::{condition, literal, noun_phrase, rule_body, starts_noun_phrase, subject};

/// Parses one source file into `out`.
pub fn parse_file(file: &str, src: &str, out: &mut Source) -> Result<(), Error> {
    for st in statements(file, src)? {
        statement(&st, out)?;
    }
    Ok(())
}

fn statement(st: &Stmt, out: &mut Source) -> Result<(), Error> {
    let at = Loc { file: st.file.clone(), line: st.line };
    let first = match st.lines[0].first() {
        Some(Tok::Word(w)) => w.clone(),
        _ => return Err(st.error("a statement starts with a word")),
    };
    match first.as_str() {
        "module" => module(st, at, out),
        "kind" => kind(st, at, out),
        "effect" => effect(st, at, out),
        "rule" => rule(st, at, out),
        "define" => define(st, at, out),
        "desired" => goal(st, at, out),
        "when" => reaction(st, at, out),
        w if w.starts_with(char::is_uppercase) => needs(st, at, out),
        _ => Err(st.error(format!(
            "unknown statement `{first}`: expected module, kind, effect, rule, define, desired, when, or `Kind needs …`"
        ))),
    }
}

/// Tokens back to text, for read-backs: no space before `'s` or `,`.
fn text(toks: &[Tok]) -> String {
    let mut out = String::new();
    for t in toks {
        if !out.is_empty() && !matches!(t, Tok::Poss | Tok::Sym(',')) {
            out.push(' ');
        }
        out.push_str(&t.to_string());
    }
    out
}

/// The tokens after the statement's first `:`.
fn after_colon(toks: &[Tok]) -> &[Tok] {
    toks.iter().position(|t| *t == Tok::Sym(':')).map_or(&[], |i| &toks[i + 1..])
}

fn number<T: std::str::FromStr>(c: &mut Cursor, what: &str) -> Result<T, Error> {
    match c.peek() {
        Some(Tok::Num(n)) => {
            let n = n.clone();
            c.next();
            n.parse().map_err(|_| c.error(format!("{what} must be a whole number, found `{n}`")))
        }
        _ => Err(c.error(format!("expected {what}, found {}", c.found()))),
    }
}

/// `30 seconds`, `1 day`, `3 days` and so on, in seconds.
fn duration(c: &mut Cursor) -> Result<u64, Error> {
    let n: u64 = number(c, "a duration")?;
    let unit = c.word()?;
    let secs = match unit.trim_end_matches('s') {
        "second" => 1,
        "minute" => 60,
        "hour" => 3_600,
        "day" => 86_400,
        "week" => 604_800,
        _ => return Err(c.error(format!("unknown time unit `{unit}`: use seconds, minutes, hours, days or weeks"))),
    };
    Ok(n * secs)
}

fn type_name(c: &mut Cursor) -> Result<TypeName, Error> {
    let w = c.word()?;
    Ok(match w.as_str() {
        "Text" => TypeName::Text,
        "Bool" => TypeName::Bool,
        "Money" => TypeName::Money,
        "Count" => TypeName::Count,
        _ if w.starts_with(char::is_uppercase) => TypeName::Kind(w),
        _ => return Err(c.error(format!("unknown type `{w}`: use Text, Bool, Money, Count or a kind"))),
    })
}

/// `module shop version 1, currency EUR`
fn module(st: &Stmt, at: Loc, out: &mut Source) -> Result<(), Error> {
    let toks = st.tokens();
    let mut c = Cursor::new(&toks, &st.file, st.line);
    c.expect_word("module")?;
    let name = c.word()?;
    c.expect_word("version")?;
    let version = number(&mut c, "a version")?;
    c.expect_sym(',')?;
    c.expect_word("currency")?;
    let currency = c.word()?;
    c.expect_end()?;
    if out.module.is_some() {
        return Err(st.error("a second `module` statement"));
    }
    out.module = Some(Module { name, version, currency, at });
    Ok(())
}

/// `kind Order { country: Text, total: Money, cancelled: Bool = no }`
fn kind(st: &Stmt, at: Loc, out: &mut Source) -> Result<(), Error> {
    let toks = st.tokens();
    let mut c = Cursor::new(&toks, &st.file, st.line);
    c.expect_word("kind")?;
    let name = c.kind_name()?;
    c.expect_sym('{')?;
    let mut attrs = vec![];
    if !c.eat_sym('}') {
        loop {
            let attr = c.word()?;
            c.expect_sym(':')?;
            let ty = type_name(&mut c)?;
            let default = if c.eat_sym('=') {
                match literal(&mut c)? {
                    Some(l) => Some(l),
                    None => return Err(c.error(format!("expected a value after `=`, found {}", c.found()))),
                }
            } else {
                None
            };
            attrs.push(AttrDecl { name: attr, ty, default });
            if c.eat_sym('}') {
                break;
            }
            c.expect_sym(',')?;
        }
    }
    c.expect_end()?;
    out.kinds.push(KindDecl { name, attrs, at });
    Ok(())
}

/// `Order needs Payment, Shipment [while cond]`
fn needs(st: &Stmt, at: Loc, out: &mut Source) -> Result<(), Error> {
    let toks = st.tokens();
    let mut c = Cursor::new(&toks, &st.file, st.line);
    let owner = c.kind_name()?;
    c.expect_word("needs")?;
    let mut parts = vec![c.kind_name()?];
    while c.eat_sym(',') {
        parts.push(c.kind_name()?);
    }
    let cond = if c.eat_word("while") { Some(condition(&mut c)?) } else { None };
    c.expect_end()?;
    out.needs.push(NeedsDecl { owner, parts, cond, at });
    Ok(())
}

/// A field that an effect sends: a noun phrase, or a bare attribute such as `amount`.
fn field(c: &mut Cursor) -> Result<NounPhrase, Error> {
    if starts_noun_phrase(c) {
        return noun_phrase(c);
    }
    let mut np = NounPhrase { head: Head::It, steps: vec![c.word()?] };
    while c.eat_poss() {
        np.steps.push(c.word()?);
    }
    Ok(np)
}

/// `ok [with a: T, b: T] [| fails with x, y]`
fn outcomes(c: &mut Cursor) -> Result<(String, Vec<(String, TypeName)>, Vec<String>), Error> {
    let success = c.word()?;
    let mut data = vec![];
    if c.eat_word("with") {
        loop {
            let name = c.word()?;
            c.expect_sym(':')?;
            data.push((name, type_name(c)?));
            if !c.eat_sym(',') {
                break;
            }
        }
    }
    let mut failures = vec![];
    if c.eat_sym('|') {
        c.expect_word("fails")?;
        c.expect_word("with")?;
        failures.push(c.word()?);
        while c.eat_sym(',') {
            failures.push(c.word()?);
        }
    }
    c.expect_end()?;
    Ok((success, data, failures))
}

/// `effect <verb> <Kind> via <adapter> within <duration>`, then indented
/// `sends …`, optionally `marks …`, and `reports …` lines.
fn effect(st: &Stmt, at: Loc, out: &mut Source) -> Result<(), Error> {
    let mut c = Cursor::new(&st.lines[0], &st.file, st.line);
    c.expect_word("effect")?;
    let verb = c.word()?;
    let kind = c.kind_name()?;
    c.expect_word("via")?;
    let adapter = c.word()?;
    c.expect_word("within")?;
    let within_secs = duration(&mut c)?;
    c.expect_end()?;
    let (mut sends, mut marks, mut reports) = (None, None, None);
    for line in &st.lines[1..] {
        let mut c = Cursor::new(line, &st.file, st.line);
        if c.eat_word("sends") {
            let mut list = vec![field(&mut c)?];
            while c.eat_sym(',') {
                list.push(field(&mut c)?);
            }
            c.expect_end()?;
            sends = Some(list);
        } else if c.eat_word("marks") {
            marks = Some(c.word()?);
            c.expect_end()?;
        } else if c.eat_word("reports") {
            reports = Some(outcomes(&mut c)?);
        } else {
            return Err(c.error(format!("expected `sends`, `marks` or `reports`, found {}", c.found())));
        }
    }
    let sends = sends.ok_or_else(|| st.error("an effect needs a `sends` line saying what the adapter receives"))?;
    let (success, data, failures) = reports.ok_or_else(|| st.error("an effect needs a `reports` line"))?;
    out.effects.push(EffectDecl { verb, kind, adapter, within_secs, sends, marks, success, data, failures, at });
    Ok(())
}

/// `rule <name>: <every … | no …>`
fn rule(st: &Stmt, at: Loc, out: &mut Source) -> Result<(), Error> {
    let toks = st.tokens();
    let mut c = Cursor::new(&toks, &st.file, st.line);
    c.expect_word("rule")?;
    let name = c.word()?;
    c.expect_sym(':')?;
    let body = rule_body(&mut c)?;
    c.expect_end()?;
    out.rules.push(RuleDecl { name, body, source: text(after_colon(&toks)), at });
    Ok(())
}

/// `define: an Order is paid when <cond>`
fn define(st: &Stmt, at: Loc, out: &mut Source) -> Result<(), Error> {
    let toks = st.tokens();
    let mut c = Cursor::new(&toks, &st.file, st.line);
    c.expect_word("define")?;
    c.expect_sym(':')?;
    if !(c.eat_word("a") || c.eat_word("an")) {
        return Err(c.error(format!("expected `a` or `an`, found {}", c.found())));
    }
    let kind = c.kind_name()?;
    c.expect_word("is")?;
    let state = c.word()?;
    c.expect_word("when")?;
    let cond = condition(&mut c)?;
    c.expect_end()?;
    out.defines.push(DefineDecl { kind, state, cond, at });
    Ok(())
}

/// `desired [within 3 days]: every <subject> is <state> [and <state> …]`
fn goal(st: &Stmt, at: Loc, out: &mut Source) -> Result<(), Error> {
    let toks = st.tokens();
    let mut c = Cursor::new(&toks, &st.file, st.line);
    c.expect_word("desired")?;
    let within_secs = if c.eat_word("within") { Some(duration(&mut c)?) } else { None };
    c.expect_sym(':')?;
    c.expect_word("every")?;
    let subject = subject(&mut c)?;
    c.expect_word("is")?;
    let mut states = vec![c.word()?];
    while c.eat_word("and") {
        states.push(c.word()?);
    }
    c.expect_end()?;
    out.goals.push(GoalDecl { subject, states, within_secs, source: text(after_colon(&toks)), at });
    Ok(())
}

/// `when a Payment is declined: its Order is cancelled [and …]`
fn reaction(st: &Stmt, at: Loc, out: &mut Source) -> Result<(), Error> {
    let toks = st.tokens();
    let mut c = Cursor::new(&toks, &st.file, st.line);
    c.expect_word("when")?;
    if !(c.eat_word("a") || c.eat_word("an")) {
        return Err(c.error(format!("expected `a` or `an`, found {}", c.found())));
    }
    let kind = c.kind_name()?;
    c.expect_word("is")?;
    let outcome = c.word()?;
    c.expect_sym(':')?;
    let mut actions = vec![action(&mut c)?];
    while c.eat_word("and") {
        actions.push(action(&mut c)?);
    }
    c.expect_end()?;
    out.reactions.push(ReactionDecl { kind, outcome, actions, at });
    Ok(())
}

/// `its Order is cancelled`, `the Order is not cancelled`
fn action(c: &mut Cursor) -> Result<Action, Error> {
    let target = noun_phrase(c)?;
    c.expect_word("is")?;
    let value = !c.eat_word("not");
    let attr = c.word()?;
    Ok(Action { target, attr, value })
}
```

```rust
//! Read-backs (spec §3.4): a rule's formula and its paraphrase, generated
//! from the compiled rule with fixed templates. No model is involved (D4).

use crate::ir::{Body, Cond, Lit, Op, Operand, Path, Program, Rule, Step};

/// `for each Declaration d: d.value ≤ d.form.order.total`
pub fn formula(p: &Program, r: &Rule) -> String {
    let v: String = r.subject.chars().next().map_or_else(|| "x".to_string(), |c| c.to_lowercase().collect());
    let f = |c: &Cond| cond_formula(p, &r.subject, &v, c);
    let filter: Vec<String> = r.filter.iter().map(&f).collect();
    let body = match &r.body {
        Body::Every(c) if filter.is_empty() => f(c),
        Body::Every(c) => format!("{} implies {}", filter.join(" and "), f(c)),
        Body::No { pred, unless } => {
            let mut lhs = filter;
            lhs.push(f(pred));
            match unless {
                Some(u) => format!("{} implies {}", lhs.join(" and "), f(u)),
                None => format!("not ({})", lhs.join(" and ")),
            }
        }
    };
    format!("for each {} {v}: {body}", r.subject)
}

/// `each declaration on its own: its value is at most its form's order's total`
pub fn paraphrase(p: &Program, r: &Rule) -> String {
    let k = words_of_kind(&r.subject);
    let w = |c: &Cond| cond_words(p, &r.subject, c);
    let filter: Vec<String> = r.filter.iter().map(&w).collect();
    let scope = if filter.is_empty() { String::new() } else { format!(" where {}", filter.join(" and ")) };
    match &r.body {
        Body::Every(c) => format!("each {k}{scope} on its own: {}", w(c)),
        Body::No { pred, unless } => {
            let pred = w(pred);
            let pred = pred.strip_prefix("it ").unwrap_or(&pred);
            let tail = unless.as_ref().map_or_else(String::new, |u| format!(" unless {}", w(u)));
            format!("no {k}{scope} ever {pred}{tail}")
        }
    }
}

fn cond_formula(p: &Program, kind: &str, v: &str, c: &Cond) -> String {
    match c {
        Cond::Cmp { left, op, right } => format!(
            "{} {} {}",
            path_formula(p, kind, v, left),
            op_symbol(*op),
            operand(p, right, |x| path_formula(p, kind, v, x))
        ),
        Cond::State { node, state, negated } => format!("{} is {}{state}", path_formula(p, kind, v, node), not(*negated)),
        Cond::Has { node, part, state, negated } => {
            let filter = state.as_ref().map_or_else(String::new, |s| format!(" where s is {s}"));
            let inner = format!("exists(s in {}.{part}{filter})", path_formula(p, kind, v, node));
            if *negated { format!("not {inner}") } else { inner }
        }
        Cond::And(cs) => cs.iter().map(|c| cond_formula(p, kind, v, c)).collect::<Vec<_>>().join(" and "),
        Cond::Or(cs) => format!("({})", cs.iter().map(|c| cond_formula(p, kind, v, c)).collect::<Vec<_>>().join(" or ")),
    }
}

fn cond_words(p: &Program, kind: &str, c: &Cond) -> String {
    match c {
        Cond::Cmp { left, op, right } => format!(
            "{} {} {}",
            path_words(p, kind, left),
            op_words(*op),
            operand(p, right, |x| path_words(p, kind, x))
        ),
        Cond::State { node, state, negated } => format!("{} is {}{state}", path_words(p, kind, node), not(*negated)),
        Cond::Has { node, part, state, negated } => {
            let that = state.as_ref().map_or_else(String::new, |s| format!(" that is {s}"));
            let a = if *negated { "no" } else { "a" };
            format!("{} has {a} {}{that}", path_words(p, kind, node), words_of_kind(part))
        }
        Cond::And(cs) => cs.iter().map(|c| cond_words(p, kind, c)).collect::<Vec<_>>().join(" and "),
        Cond::Or(cs) => cs.iter().map(|c| cond_words(p, kind, c)).collect::<Vec<_>>().join(" or "),
    }
}

fn not(negated: bool) -> &'static str {
    if negated { "not " } else { "" }
}

fn operand(p: &Program, o: &Operand, path: impl Fn(&Path) -> String) -> String {
    match o {
        Operand::Lit(l) => lit_text(p, l),
        Operand::Path(x) => path(x),
    }
}

/// A literal as it is written: `"France"`, `120 EUR`, `12.50 EUR`, `3`, `yes`.
pub fn lit_text(p: &Program, l: &Lit) -> String {
    match l {
        Lit::Text(s) => format!("\"{s}\""),
        Lit::Bool(true) => "yes".into(),
        Lit::Bool(false) => "no".into(),
        Lit::Count(n) => n.to_string(),
        Lit::Money(c) if c % 100 == 0 => format!("{} {}", c / 100, p.currency),
        Lit::Money(c) => format!("{}.{:02} {}", c / 100, (c % 100).abs(), p.currency),
    }
}

fn op_symbol(op: Op) -> &'static str {
    match op {
        Op::Eq => "=",
        Op::Ne => "≠",
        Op::Lt => "<",
        Op::Le => "≤",
        Op::Gt => ">",
        Op::Ge => "≥",
    }
}

fn op_words(op: Op) -> &'static str {
    match op {
        Op::Eq => "is",
        Op::Ne => "is not",
        Op::Lt => "is less than",
        Op::Le => "is at most",
        Op::Gt => "is more than",
        Op::Ge => "is at least",
    }
}

/// Each step's name, and whether it is a part: an attribute, a part's kind,
/// or, for an owner step, the name of the attribute that holds the owner.
fn step_names(p: &Program, kind: &str, path: &Path) -> Vec<(String, bool)> {
    let mut out = vec![];
    let mut cur = kind.to_string();
    for s in &path.steps {
        match s {
            Step::Attr(a) => out.push((a.clone(), false)),
            Step::Part(k) => {
                out.push((k.clone(), true));
                cur = k.clone();
            }
            Step::Owner => match p.kind(&cur).and_then(|k| k.owner.clone()) {
                Some(o) => {
                    out.push((o.attr, false));
                    cur = o.kind;
                }
                None => out.push(("owner".into(), false)),
            },
        }
    }
    out
}

/// `d.form.order.total`
fn path_formula(p: &Program, kind: &str, v: &str, path: &Path) -> String {
    step_names(p, kind, path).iter().fold(v.to_string(), |acc, (n, _)| format!("{acc}.{n}"))
}

/// `its form's order's total`, or `it` for the subject itself.
fn path_words(p: &Program, kind: &str, path: &Path) -> String {
    let names: Vec<String> =
        step_names(p, kind, path).into_iter().map(|(n, part)| if part { words_of_kind(&n) } else { n }).collect();
    if names.is_empty() { "it".into() } else { format!("its {}", names.join("'s ")) }
}

/// `CustomsForm` becomes `customs form`.
pub fn words_of_kind(k: &str) -> String {
    let mut out = String::new();
    for (i, ch) in k.chars().enumerate() {
        if ch.is_uppercase() && i > 0 {
            out.push(' ');
        }
        out.extend(ch.to_lowercase());
    }
    out
}
```

```rust
//! From syntax to the compiled program (spec §4.1–§4.2, appendix B.3). It
//! resolves every name, checks types, owners and states, and attaches every
//! rule's read-back. Every check is fixed; no model decides anything (D4).

use crate::ast::{self, CmpOp, Head, Literal, Loc, NounPhrase, Source, Term, TypeName};
use crate::ir::{
    Action, Attr, Body, Cond, Define, Effect, Goal, Kind, Lit, Need, Op, Operand, OwnerRef, Path, Program, Reaction,
    Rule, Step, Ty,
};
use crate::lex::Error;
use crate::readback;

/// Checks a parsed module and compiles it, reporting every error it finds.
pub fn check(src: &Source) -> Result<Program, Vec<Error>> {
    let mut cx = Checker { errors: vec![] };
    let prog = cx.program(src);
    if cx.errors.is_empty() { Ok(prog) } else { Err(cx.errors) }
}

/// Where a noun phrase ends: at a node of some kind, or at a value of some type.
enum End {
    Node(String),
    Value(Ty),
}

fn err(at: &Loc, msg: impl Into<String>) -> Error {
    Error { file: at.file.clone(), line: at.line, msg: msg.into() }
}

fn value_type(t: &TypeName) -> Option<Ty> {
    match t {
        TypeName::Text => Some(Ty::Text),
        TypeName::Bool => Some(Ty::Bool),
        TypeName::Money => Some(Ty::Money),
        TypeName::Count => Some(Ty::Count),
        TypeName::Kind(_) => None,
    }
}

/// A noun phrase as written, for messages.
fn show(np: &NounPhrase) -> String {
    let mut s = match (&np.head, np.steps.is_empty()) {
        (Head::It, true) => "it".to_string(),
        (Head::It, false) => "its".to_string(),
        (Head::The(k), _) => format!("the {k}"),
    };
    for (i, w) in np.steps.iter().enumerate() {
        s.push_str(if i == 0 && matches!(np.head, Head::It) { " " } else { "'s " });
        s.push_str(w);
    }
    s
}

struct Checker {
    errors: Vec<Error>,
}

impl Checker {
    fn program(&mut self, src: &Source) -> Program {
        let (module, version, currency) = match &src.module {
            Some(m) => (m.name.clone(), m.version, m.currency.clone()),
            None => {
                self.errors.push(Error { file: String::new(), line: 0, msg: "no `module` statement".into() });
                (String::new(), 0, String::new())
            }
        };
        let mut p = Program {
            module,
            version,
            currency,
            kinds: vec![],
            needs: vec![],
            effects: vec![],
            rules: vec![],
            defines: vec![],
            goals: vec![],
            reactions: vec![],
        };
        self.kinds(src, &mut p);
        let conds = self.owners(src, &mut p);
        self.effects(src, &mut p);
        self.defines(src, &mut p);
        for (i, owner, at, cond) in conds {
            let c = self.cond(&p, at, &owner, cond);
            p.needs[i].cond = c;
        }
        self.rules(src, &mut p);
        self.goals(src, &mut p);
        self.reactions(src, &mut p);
        p
    }

    fn kinds(&mut self, src: &Source, p: &mut Program) {
        for k in &src.kinds {
            if p.kind(&k.name).is_some() {
                self.errors.push(err(&k.at, format!("kind {} is declared twice", k.name)));
                continue;
            }
            let mut seen: Vec<&str> = vec![];
            let mut attrs = vec![];
            for a in &k.attrs {
                if seen.contains(&a.name.as_str()) {
                    self.errors.push(err(&k.at, format!("{} has two attributes called {}", k.name, a.name)));
                    continue;
                }
                seen.push(&a.name);
                let Some(ty) = value_type(&a.ty) else { continue }; // an owner reference: see `owners`
                let default = match &a.default {
                    None => None,
                    Some(l) => match self.lit(&k.at, l, &p.currency) {
                        Some((lit, t)) if t == ty => Some(lit),
                        Some((_, t)) => {
                            self.errors.push(err(&k.at, format!("{}.{} is {ty:?} but its default is {t:?}", k.name, a.name)));
                            None
                        }
                        None => None,
                    },
                };
                attrs.push(Attr { name: a.name.clone(), ty, default });
            }
            p.kinds.push(Kind { name: k.name.clone(), attrs, owner: None });
        }
    }

    /// A literal's value and type. Money must be in the module's currency.
    fn lit(&mut self, at: &Loc, l: &Literal, currency: &str) -> Option<(Lit, Ty)> {
        Some(match l {
            Literal::Text(s) => (Lit::Text(s.clone()), Ty::Text),
            Literal::Bool(b) => (Lit::Bool(*b), Ty::Bool),
            Literal::Count(n) => (Lit::Count(*n), Ty::Count),
            Literal::Money { cents, currency: c } if c == currency => (Lit::Money(*cents), Ty::Money),
            Literal::Money { currency: c, .. } => {
                self.errors.push(err(at, format!("an amount in {c} is not in this module's currency, {currency}")));
                return None;
            }
        })
    }

    /// Who owns which part (spec §3.2: a part has exactly one attribute of its
    /// owner's kind). Returns the needs' conditions, which are resolved once
    /// effects and definitions are known.
    fn owners<'s>(&mut self, src: &'s Source, p: &mut Program) -> Vec<(usize, String, &'s Loc, &'s ast::Cond)> {
        let mut conds = vec![];
        for n in &src.needs {
            if p.kind(&n.owner).is_none() {
                self.errors.push(err(&n.at, format!("unknown kind {}", n.owner)));
                continue;
            }
            for part in &n.parts {
                let Some(decl) = src.kinds.iter().find(|k| k.name == *part) else {
                    self.errors.push(err(&n.at, format!("unknown kind {part}")));
                    continue;
                };
                let owner_type = TypeName::Kind(n.owner.clone());
                let refs: Vec<&str> = decl.attrs.iter().filter(|a| a.ty == owner_type).map(|a| a.name.as_str()).collect();
                if refs.len() != 1 {
                    self.errors.push(err(
                        &n.at,
                        format!("{part} needs exactly one attribute of kind {} to name its owner; it has {}", n.owner, refs.len()),
                    ));
                    continue;
                }
                let kind = p.kinds.iter_mut().find(|k| k.name == *part).expect("declared kinds are compiled");
                if let Some(o) = &kind.owner {
                    if o.kind != n.owner {
                        self.errors.push(err(&n.at, format!("{part} is already a part of {}; a part has one owner", o.kind)));
                        continue;
                    }
                }
                kind.owner = Some(OwnerRef { attr: refs[0].to_string(), kind: n.owner.clone() });
                if let Some(c) = &n.cond {
                    conds.push((p.needs.len(), n.owner.clone(), &n.at, c));
                }
                p.needs.push(Need { owner: n.owner.clone(), part: part.clone(), cond: None });
            }
        }
        for k in &src.kinds {
            for a in &k.attrs {
                let TypeName::Kind(target) = &a.ty else { continue };
                let owner = p.kind(&k.name).and_then(|x| x.owner.as_ref());
                if owner.is_none_or(|o| o.kind != *target) {
                    self.errors.push(err(
                        &k.at,
                        format!("{}.{}: {target} is not the owner of {}; in slice 1 a kind refers only to its owner", k.name, a.name, k.name),
                    ));
                }
            }
        }
        for k in &p.kinds {
            let mut seen = vec![k.name.clone()];
            let mut cur = k.owner.as_ref().map(|o| o.kind.clone());
            while let Some(c) = cur {
                if seen.contains(&c) {
                    self.errors.push(Error { file: String::new(), line: 0, msg: format!("needs loop: {} → {c}", seen.join(" → ")) });
                    break;
                }
                seen.push(c.clone());
                cur = p.kind(&c).and_then(|x| x.owner.as_ref()).map(|o| o.kind.clone());
            }
        }
        conds
    }

    fn effects(&mut self, src: &Source, p: &mut Program) {
        for e in &src.effects {
            if p.kind(&e.kind).is_none() {
                self.errors.push(err(&e.at, format!("unknown kind {}", e.kind)));
                continue;
            }
            if p.effect_of(&e.kind).is_some() {
                self.errors.push(err(&e.at, format!("{} already has an effect; slice 1 allows one per kind", e.kind)));
                continue;
            }
            let mut data = vec![];
            for (name, t) in &e.data {
                let Some(ty) = value_type(t) else {
                    self.errors.push(err(&e.at, format!("an answer carries values, not a {t:?}")));
                    continue;
                };
                let kind = p.kinds.iter_mut().find(|k| k.name == e.kind).expect("checked above");
                match kind.attr(name).map(|a| a.ty) {
                    Some(have) if have != ty => {
                        self.errors.push(err(&e.at, format!("{}.{name} is {have:?}, but the answer gives {ty:?}", e.kind)));
                        continue;
                    }
                    Some(_) => {}
                    None => kind.attrs.push(Attr { name: name.clone(), ty, default: None }),
                }
                data.push((name.clone(), ty));
            }
            let mut sends = vec![];
            for np in &e.sends {
                match self.np(p, &e.at, &e.kind, np) {
                    Some((path, End::Value(_))) => sends.push((np.steps.last().cloned().unwrap_or_default(), path)),
                    Some((_, End::Node(k))) => {
                        self.errors.push(err(&e.at, format!("an effect sends values; `{}` is a {k}", show(np))));
                    }
                    None => {}
                }
            }
            p.effects.push(Effect {
                kind: e.kind.clone(),
                verb: e.verb.clone(),
                adapter: e.adapter.clone(),
                within_secs: e.within_secs,
                sends,
                marks: e.marks.clone(),
                success: e.success.clone(),
                data,
                failures: e.failures.clone(),
            });
        }
    }

    /// Definitions are resolved in order, so a definition can use only the
    /// states defined before it. That rules out cycles.
    fn defines(&mut self, src: &Source, p: &mut Program) {
        for d in &src.defines {
            let Some(k) = p.kind(&d.kind) else {
                self.errors.push(err(&d.at, format!("unknown kind {}", d.kind)));
                continue;
            };
            if k.attr(&d.state).is_some() || p.states(&d.kind).contains(&d.state) {
                self.errors.push(err(&d.at, format!("{} already has a state or attribute called `{}`", d.kind, d.state)));
                continue;
            }
            let Some(cond) = self.cond(p, &d.at, &d.kind, &d.cond) else { continue };
            p.defines.push(Define { kind: d.kind.clone(), state: d.state.clone(), cond });
        }
    }

    fn rules(&mut self, src: &Source, p: &mut Program) {
        for r in &src.rules {
            if p.rules.iter().any(|x| x.name == r.name) {
                self.errors.push(err(&r.at, format!("two rules are called {}", r.name)));
                continue;
            }
            let (ast::RuleBody::Every { subject, .. } | ast::RuleBody::No { subject, .. }) = &r.body;
            if p.kind(&subject.kind).is_none() {
                self.errors.push(err(&r.at, format!("unknown kind {}", subject.kind)));
                continue;
            }
            let Some(filter) = self.filter(p, &r.at, subject) else { continue };
            let body = match &r.body {
                ast::RuleBody::Every { cond, .. } => match self.cond(p, &r.at, &subject.kind, cond) {
                    Some(c) => Body::Every(c),
                    None => continue,
                },
                ast::RuleBody::No { pred, unless, .. } => {
                    let Some(pred) = self.cond(p, &r.at, &subject.kind, pred) else { continue };
                    let unless = match unless {
                        Some(u) => match self.cond(p, &r.at, &subject.kind, u) {
                            Some(c) => Some(c),
                            None => continue,
                        },
                        None => None,
                    };
                    Body::No { pred, unless }
                }
            };
            let mut rule = Rule {
                name: r.name.clone(),
                subject: subject.kind.clone(),
                filter,
                body,
                source: r.source.clone(),
                formula: String::new(),
                paraphrase: String::new(),
                tier: "local".into(),
            };
            rule.formula = readback::formula(p, &rule);
            rule.paraphrase = readback::paraphrase(p, &rule);
            p.rules.push(rule);
        }
    }

    fn goals(&mut self, src: &Source, p: &mut Program) {
        for g in &src.goals {
            let kind = &g.subject.kind;
            let Some(k) = p.kind(kind) else {
                self.errors.push(err(&g.at, format!("unknown kind {kind}")));
                continue;
            };
            if let Some(o) = &k.owner {
                self.errors.push(err(&g.at, format!("in slice 1 a goal is about a root kind; {kind} is a part of {}", o.kind)));
                continue;
            }
            let Some(filter) = self.filter(p, &g.at, &g.subject) else { continue };
            let known: Vec<bool> = g.states.iter().map(|s| self.state(p, &g.at, kind, s).is_some()).collect();
            if known.contains(&false) {
                continue;
            }
            p.goals.push(Goal {
                kind: kind.clone(),
                filter,
                states: g.states.clone(),
                within_secs: g.within_secs,
                source: g.source.clone(),
            });
        }
    }

    fn reactions(&mut self, src: &Source, p: &mut Program) {
        for r in &src.reactions {
            let Some(e) = p.effect_of(&r.kind) else {
                self.errors.push(err(&r.at, format!("a {} has no effect, so nothing reports `{}` for it", r.kind, r.outcome)));
                continue;
            };
            if e.success != r.outcome && !e.failures.contains(&r.outcome) {
                self.errors.push(err(
                    &r.at,
                    format!("a {} reports `{}` or fails with {}, not `{}`", r.kind, e.success, e.failures.join(", "), r.outcome),
                ));
                continue;
            }
            let mut actions = vec![];
            for a in &r.actions {
                match self.np(p, &r.at, &r.kind, &a.target) {
                    Some((target, End::Node(k))) => {
                        let is_bool = p.kind(&k).and_then(|x| x.attr(&a.attr)).is_some_and(|x| x.ty == Ty::Bool);
                        if is_bool {
                            actions.push(Action { target, attr: a.attr.clone(), value: a.value });
                        } else {
                            self.errors.push(err(&r.at, format!("a {k} has no Bool attribute `{}` to set", a.attr)));
                        }
                    }
                    Some((_, End::Value(_))) => {
                        self.errors.push(err(&r.at, format!("`{}` is a value; an action sets an attribute of a node", show(&a.target))));
                    }
                    None => {}
                }
            }
            p.reactions.push(Reaction { kind: r.kind.clone(), outcome: r.outcome.clone(), actions });
        }
    }

    fn filter(&mut self, p: &Program, at: &Loc, s: &ast::Subject) -> Option<Vec<Cond>> {
        s.filter.iter().map(|c| self.cond(p, at, &s.kind, c)).collect()
    }

    /// Resolves a noun phrase from a node of kind `from` (spec B.3.8): each
    /// word is an attribute, a part, or the owner, tried in that order.
    fn np(&mut self, p: &Program, at: &Loc, from: &str, np: &NounPhrase) -> Option<(Path, End)> {
        let mut steps = vec![];
        let mut cur = from.to_string();
        if let Head::The(k) = &np.head {
            while cur != *k {
                match p.kind(&cur).and_then(|x| x.owner.as_ref()) {
                    Some(o) => {
                        steps.push(Step::Owner);
                        cur = o.kind.clone();
                    }
                    None => {
                        self.errors.push(err(at, format!("`the {k}`: a {from} is not part of a {k}")));
                        return None;
                    }
                }
            }
        }
        for (i, w) in np.steps.iter().enumerate() {
            let kind = p.kind(&cur)?;
            if let Some(a) = kind.attr(w) {
                if let Some(next) = np.steps.get(i + 1) {
                    self.errors.push(err(at, format!("`{}`: {w} is a value, so it has no `{next}`", show(np))));
                    return None;
                }
                steps.push(Step::Attr(w.clone()));
                return Some((Path { steps }, End::Value(a.ty)));
            }
            if p.needs.iter().any(|n| n.owner == cur && n.part == *w) {
                steps.push(Step::Part(w.clone()));
                cur = w.clone();
                continue;
            }
            match kind.owner.as_ref().filter(|o| o.attr == *w || o.kind == *w) {
                Some(o) => {
                    steps.push(Step::Owner);
                    cur = o.kind.clone();
                }
                None => {
                    self.errors.push(err(at, format!("a {cur} has no attribute, part or owner called `{w}`")));
                    return None;
                }
            }
        }
        Some((Path { steps }, End::Node(cur)))
    }

    fn cond(&mut self, p: &Program, at: &Loc, from: &str, c: &ast::Cond) -> Option<Cond> {
        match c {
            ast::Cond::And(cs) => Some(Cond::And(cs.iter().map(|c| self.cond(p, at, from, c)).collect::<Option<Vec<_>>>()?)),
            ast::Cond::Or(cs) => Some(Cond::Or(cs.iter().map(|c| self.cond(p, at, from, c)).collect::<Option<Vec<_>>>()?)),
            ast::Cond::Has { owner, negated, kind, state } => {
                let (node, end) = self.np(p, at, from, owner)?;
                let End::Node(k) = end else {
                    self.errors.push(err(at, format!("`{}` is a value; only a node has parts", show(owner))));
                    return None;
                };
                if !p.needs.iter().any(|n| n.owner == k && n.part == *kind) {
                    self.errors.push(err(at, format!("a {k} does not need a {kind}")));
                    return None;
                }
                if let Some(s) = state {
                    self.state(p, at, kind, s)?;
                }
                Some(Cond::Has { node, part: kind.clone(), state: state.clone(), negated: *negated })
            }
            ast::Cond::Cmp { left, op, right } => {
                let (path, end) = self.np(p, at, from, left)?;
                let ty = match end {
                    End::Value(t @ (Ty::Money | Ty::Count)) => t,
                    End::Value(t) => {
                        self.errors.push(err(
                            at,
                            format!("`{}` is {t:?}; only amounts and counts compare with at most, at least, more than or less than", show(left)),
                        ));
                        return None;
                    }
                    End::Node(k) => {
                        self.errors.push(err(at, format!("`{}` is a {k}, not an amount or a count", show(left))));
                        return None;
                    }
                };
                let right = self.operand(p, at, from, right, ty)?;
                let op = match op {
                    CmpOp::AtMost => Op::Le,
                    CmpOp::AtLeast => Op::Ge,
                    CmpOp::MoreThan => Op::Gt,
                    CmpOp::LessThan => Op::Lt,
                };
                Some(Cond::Cmp { left: path, op, right })
            }
            ast::Cond::Is { left, negated, right } => {
                let (path, end) = self.np(p, at, from, left)?;
                match end {
                    End::Node(k) => {
                        let Term::Word(s) = right else {
                            self.errors.push(err(at, format!("`{}` is a {k}; compare it with a state: {}", show(left), p.states(&k).join(", "))));
                            return None;
                        };
                        self.state(p, at, &k, s)?;
                        Some(Cond::State { node: path, state: s.clone(), negated: *negated })
                    }
                    End::Value(ty) => {
                        let right = self.operand(p, at, from, right, ty)?;
                        Some(Cond::Cmp { left: path, op: if *negated { Op::Ne } else { Op::Eq }, right })
                    }
                }
            }
        }
    }

    /// The other side of a comparison with a value of type `ty`. A bare word
    /// is text when `ty` is Text (spec B.3.7).
    fn operand(&mut self, p: &Program, at: &Loc, from: &str, t: &Term, ty: Ty) -> Option<Operand> {
        let (operand, found) = match t {
            Term::Lit(l) => {
                let (lit, t) = self.lit(at, l, &p.currency)?;
                (Operand::Lit(lit), t)
            }
            Term::Word(w) if ty == Ty::Text => (Operand::Lit(Lit::Text(w.clone())), Ty::Text),
            Term::Word(w) => {
                self.errors.push(err(at, format!("expected a {ty:?} value, found `{w}`")));
                return None;
            }
            Term::Np(np) => match self.np(p, at, from, np)? {
                (path, End::Value(t)) => (Operand::Path(path), t),
                (_, End::Node(k)) => {
                    self.errors.push(err(at, format!("`{}` is a {k}, not a value", show(np))));
                    return None;
                }
            },
        };
        if found != ty {
            self.errors.push(err(at, format!("cannot compare a {ty:?} with a {found:?}")));
            return None;
        }
        Some(operand)
    }

    fn state(&mut self, p: &Program, at: &Loc, kind: &str, s: &str) -> Option<()> {
        let states = p.states(kind);
        if states.iter().any(|x| x == s) {
            return Some(());
        }
        self.errors.push(err(at, format!("a {kind} has no state `{s}`; its states are {}", states.join(", "))));
        None
    }
}
```

```rust
/// Compiles every `.st` file in `dir`, in file-name order.
pub fn compile_dir(dir: &std::path::Path) -> Result<ir::Program, Vec<Error>> {
    let fail = |file: String, msg: String| vec![Error { file, line: 0, msg }];
    let entries = std::fs::read_dir(dir).map_err(|e| fail(dir.display().to_string(), e.to_string()))?;

        let path = entry.path();

            let text = std::fs::read_to_string(&path).map_err(|e| fail(path.display().to_string(), e.to_string()))?;
            let name = path.file_name().map(|n| n.to_string_lossy().into_owned()).unwrap_or_default();
            files.push((name, text));
        }
    }
    if files.is_empty() {
        return Err(fail(dir.display().to_string(), "no .st files here".into()));
    }
    files.sort();
    compile(&files)
```

```rust
//! The runtime's data: values, the nodes of a unit, messages and outside
//! requests, and how each is carried in kernel payloads.

use std::collections::BTreeMap;

use suture::Value;
use suture_lang::ir::{Lit, Ty};

/// An attribute's value. Money is in cents.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Val {
    Text(String),
    Bool(bool),
    Money(i64),
    Count(i64),
}

impl Val {
    pub fn from_lit(l: &Lit) -> Val {
        match l {
            Lit::Text(s) => Val::Text(s.clone()),
            Lit::Bool(b) => Val::Bool(*b),
            Lit::Money(c) => Val::Money(*c),
            Lit::Count(n) => Val::Count(*n),
        }
    }

    pub fn ty(&self) -> Ty {
        match self {
            Val::Text(_) => Ty::Text,
            Val::Bool(_) => Ty::Bool,
            Val::Money(_) => Ty::Money,
            Val::Count(_) => Ty::Count,
        }
    }

    /// The value as people read it: `"alcohol"`, `120 EUR`, `12.50 EUR`, `3`, `yes`.
    pub fn show(&self, currency: &str) -> String {
        match self {
            Val::Text(s) => format!("\"{s}\""),
            Val::Bool(true) => "yes".into(),
            Val::Bool(false) => "no".into(),
            Val::Money(c) if c % 100 == 0 => format!("{} {currency}", c / 100),
            Val::Money(c) => format!("{}.{:02} {currency}", c / 100, (c % 100).abs()),
            Val::Count(n) => n.to_string(),
        }
    }

    fn to_value(&self) -> Value {
        match self {
            Val::Text(s) => Value::tuple([Value::from(0i64), text(s)]),
            Val::Bool(b) => Value::tuple([Value::from(1i64), Value::from(*b)]),
            Val::Money(c) => Value::tuple([Value::from(2i64), Value::from(*c)]),
            Val::Count(n) => Value::tuple([Value::from(3i64), Value::from(*n)]),
        }
    }

    fn from_value(v: &Value) -> Result<Val, String> {
        let [tag, x] = fields::<2>(v, "value")?;
        Ok(match int(tag)? {
            0 => Val::Text(string(x)?),
            1 => Val::Bool(x.as_bool().ok_or_else(|| format!("not a yes or no: {x}"))?),
            2 => Val::Money(int(x)?),
            3 => Val::Count(int(x)?),
            t => return Err(format!("unknown value tag {t}")),
        })
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Status {
    Idle,
    Requested,
    Done,
    Failed,
}

impl Status {
    fn code(self) -> i64 {
        match self {
            Status::Idle => 0,
            Status::Requested => 1,
            Status::Done => 2,
            Status::Failed => 3,
        }
    }

    fn from_code(c: i64) -> Result<Status, String> {
        Ok(match c {
            0 => Status::Idle,
            1 => Status::Requested,
            2 => Status::Done,
            3 => Status::Failed,
            _ => return Err(format!("unknown status {c}")),
        })
    }
}

/// One entity of a unit: its root, or a part (spec appendix B.3.1).
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Node {
    pub kind: String,
    pub attrs: BTreeMap<String, Val>,
    pub status: Status,
    /// What the outside world reported, once it has.
    pub outcome: Option<String>,
    /// Which attempt of its need this part is, from 1.
    pub attempt: u32,
    /// The rule its request is waiting on, if any.
    pub waiting: Option<String>,
    /// Its parts, every attempt kept, in the order they were created.
    pub parts: Vec<Node>,
}

impl Node {
    fn to_value(&self) -> Value {
        Value::tuple([
            text(&self.kind),
            Value::list(self.attrs.iter().map(|(k, v)| Value::tuple([text(k), v.to_value()]))),
            Value::from(self.status.code()),
            text(self.outcome.as_deref().unwrap_or("")),
            Value::from(i64::from(self.attempt)),
            text(self.waiting.as_deref().unwrap_or("")),
            Value::list(self.parts.iter().map(Node::to_value)),
        ])
    }

    fn from_value(v: &Value) -> Result<Node, String> {
        let [kind, attrs, status, outcome, attempt, waiting, parts] = fields::<7>(v, "node")?;
        let mut map = BTreeMap::new();
        for a in items(attrs)? {
            let [k, x] = fields::<2>(a, "attribute")?;
            map.insert(string(k)?, Val::from_value(x)?);
        }
        let some = |s: String| if s.is_empty() { None } else { Some(s) };
        Ok(Node {
            kind: string(kind)?,
            attrs: map,
            status: Status::from_code(int(status)?)?,
            outcome: some(string(outcome)?),
            attempt: u32::try_from(int(attempt)?).map_err(|e| e.to_string())?,
            waiting: some(string(waiting)?),
            parts: items(parts)?.iter().map(Node::from_value).collect::<Result<_, _>>()?,
        })
    }
}
```

```rust
//! The interpreter (spec appendix B.3): one step of a unit for one message.
//! It is a pure function of the program, the unit and the message, so
//! replaying the journal reproduces every step.

use suture_lang::ir::{Body, Cond, Effect, Op, Operand, Path, Program, Rule, Step};

use crate::state::{Ask, Msg, Node, Status, Unit, Val};

/// The most attempts of a part before its need gives up (spec §3.2).
pub const ATTEMPTS: u32 = 3;

/// A bound on settling. A unit's parts are bounded, so a valid program
/// settles long before this.
const SETTLE_ROUNDS: usize = 256;

/// The unit after a step, and the requests the step sends out.
pub struct Outcome {
    pub unit: Unit,
    pub asks: Vec<Ask>,
}

/// A new unit for a root entity: its defaults, then the given attributes.
pub fn new_unit(prog: &Program, label: &str, kind: &str, given: &[(String, Val)]) -> Result<Unit, String> {
    let k = prog.kind(kind).ok_or_else(|| format!("there is no kind {kind}"))?;
    if let Some(o) = &k.owner {
        return Err(format!("{kind} is a part of {}; its owner's needs create it", o.kind));
    }
    let mut root = blank(prog, kind, 1);
    for (name, v) in given {
        let a = k.attr(name).ok_or_else(|| format!("{kind} has no attribute {name}"))?;
        if v.ty() != a.ty {
            return Err(format!("{kind}.{name} is {:?}, not {:?}", a.ty, v.ty()));
        }
        root.attrs.insert(name.clone(), v.clone());
    }
    Ok(Unit { label: label.to_string(), root, notes: vec![], met: vec![] })
}

fn blank(prog: &Program, kind: &str, attempt: u32) -> Node {
    let attrs = prog
        .kind(kind)
        .map(|k| k.attrs.iter().filter_map(|a| a.default.as_ref().map(|d| (a.name.clone(), Val::from_lit(d)))).collect())
        .unwrap_or_default();
    Node { kind: kind.to_string(), attrs, status: Status::Idle, outcome: None, attempt, waiting: None, parts: vec![] }
}

/// One step: apply the message, then settle the unit (create, replace and
/// withdraw parts, finish parts, send the requests every rule allows), then
/// note the goals that became met.
pub fn step(prog: &Program, unit: &Unit, msg: &Msg) -> Outcome {
    let mut u = unit.clone();
    u.notes.clear();
    let mut asks = vec![];
    match msg {
        Msg::Create => {
            let attrs: Vec<String> = u.root.attrs.iter().map(|(k, v)| format!("{k} {}", v.show(&prog.currency))).collect();
            u.notes.push(format!("placed: {}", attrs.join(", ")));
        }
        Msg::Answer { key, outcome, data } => {
            if let Err(refusal) = answer(prog, &mut u, key, outcome, data) {
                let mut kept = unit.clone();
                kept.notes = vec![refusal.note];
                asks.extend(refusal.again);
                return Outcome { unit: kept, asks };
            }
        }
    }
    settle(prog, &mut u, &mut asks);
    goals(prog, &mut u);
    Outcome { unit: u, asks }
}

/// Why an answer was not recorded, and the request to send again, if any.
struct Refusal {
    note: String,
    again: Option<Ask>,
}

fn answer(prog: &Program, u: &mut Unit, key: &str, outcome: &str, data: &[(String, Val)]) -> Result<(), Refusal> {
    let open = positions(&u.root)
        .into_iter()
        .find(|at| node_at(&u.root, at).status == Status::Requested && request_key(&u.label, &u.root, at) == key);
    let Some(at) = open else {
        return Err(Refusal { note: format!("ignored an answer for {key}: no open request"), again: None });
    };
    let kind = node_at(&u.root, &at).kind.clone();
    let effect = prog.effect_of(&kind).expect("a requested part has an effect");
    let again = Some(ask_for(&u.label, &u.root, &at, effect));
    let refuse = |why: String| Refusal { note: format!("refused an answer for {key}: {why}"), again: again.clone() };
    let success = outcome == effect.success;
    if !success && !effect.failures.iter().any(|f| f == outcome) {
        return Err(refuse(format!("a {kind} cannot report `{outcome}`")));
    }
    for (name, v) in data {
        match effect.data.iter().find(|(n, _)| n == name) {
            Some((_, ty)) if *ty == v.ty() => {}
            Some((_, ty)) => return Err(refuse(format!("{name} must be {ty:?}, not {}", v.show(&prog.currency)))),
            None => return Err(refuse(format!("a {kind} answer has no field {name}"))),
        }
    }
    if success {
        if let Some((name, _)) = effect.data.iter().find(|(n, _)| !data.iter().any(|(d, _)| d == n)) {
            return Err(refuse(format!("the answer is missing {name}")));
        }
    }
    let mut t = u.root.clone();
    {
        let n = node_at_mut(&mut t, &at);
        for (name, v) in data {
            n.attrs.insert(name.clone(), v.clone());
        }
        n.outcome = Some(outcome.to_string());
        n.status = if success { Status::Done } else { Status::Failed };
        n.waiting = None;
    }
    let shown: Vec<String> = data.iter().map(|(k, v)| format!("{k} {}", v.show(&prog.currency))).collect();
    let mut notes =
        vec![if shown.is_empty() { format!("{kind} {outcome}") } else { format!("{kind} {outcome}: {}", shown.join(", ")) }];
    react(prog, &mut t, &at, &kind, outcome, &mut notes);
    if let Some(r) = violated(prog, &t) {
        return Err(Refusal { note: format!("refused by rule {}: {}", r.name, r.paraphrase), again });
    }
    u.root = t;
    u.notes.extend(notes);
    Ok(())
}

/// Applies the `when` reactions to an outcome (spec §3.3).
fn react(prog: &Program, root: &mut Node, at: &[usize], kind: &str, outcome: &str, notes: &mut Vec<String>) {
    for r in prog.reactions.iter().filter(|r| r.kind == kind && r.outcome == outcome) {
        for a in &r.actions {
            let Some(target) = locate(root, at, &a.target.steps) else { continue };
            let n = node_at_mut(root, &target);
            n.attrs.insert(a.attr.clone(), Val::Bool(a.value));
            notes.push(format!("{} is {}{}", n.kind, if a.value { "" } else { "not " }, a.attr));
        }
    }
}

fn settle(prog: &Program, u: &mut Unit, asks: &mut Vec<Ask>) {
    for _ in 0..SETTLE_ROUNDS {
        let changed = positions(&u.root)
            .iter()
            .any(|at| needs_pass(prog, u, at) || done_pass(prog, u, at) || request_pass(prog, u, at, asks));
        if !changed {
            return;
        }
    }
    u.notes.push("stopped settling: the program keeps changing this unit".into());
}

/// Creates a part an active need lacks, replaces one that failed, or
/// withdraws one whose need is no longer active and that has not reached the
/// outside world (spec §3.2, D9). Makes at most one change.
fn needs_pass(prog: &Program, u: &mut Unit, at: &[usize]) -> bool {
    enum Change {
        Add(Node, String),
        Remove(usize, String),
    }
    let change = {
        let n = node_at(&u.root, at);
        if n.status == Status::Failed {
            return false;
        }
        let mut change = None;
        for need in prog.needs.iter().filter(|need| need.owner == n.kind) {
            let active = need.cond.as_ref().is_none_or(|c| eval(prog, &u.root, at, c) == T::Yes);
            match current(n, &need.part).map(|i| (i, &n.parts[i])) {
                None if active => change = Some(Change::Add(blank(prog, &need.part, 1), format!("needs {}", need.part))),
                Some((_, p)) if active && p.status == Status::Failed && p.attempt < ATTEMPTS => {
                    let note = format!("{} {}: attempt {}", need.part, p.outcome.as_deref().unwrap_or("failed"), p.attempt + 1);
                    change = Some(Change::Add(blank(prog, &need.part, p.attempt + 1), note));
                }
                Some((i, p)) if !active && untouched(p) => {
                    change = Some(Change::Remove(i, format!("{} withdrawn", need.part)));
                }
                _ => {}
            }
            if change.is_some() {
                break;
            }
        }
        change
    };
    let n = node_at_mut(&mut u.root, at);
    match change {
        Some(Change::Add(part, note)) => {
            n.parts.push(part);
            u.notes.push(note);
            true
        }
        Some(Change::Remove(i, note)) => {
            n.parts.remove(i);
            u.notes.push(note);
            true
        }
        None => false,
    }
}

/// A part with no effect of its own is done once every active need of it is
/// done (appendix B.3.2). A root is never done; its goals describe it.
fn done_pass(prog: &Program, u: &mut Unit, at: &[usize]) -> bool {
    let n = node_at(&u.root, at);
    if at.is_empty() || n.status != Status::Idle || prog.effect_of(&n.kind).is_some() || !needs_done(prog, &u.root, at) {
        return false;
    }
    let kind = n.kind.clone();
    node_at_mut(&mut u.root, at).status = Status::Done;
    u.notes.push(format!("{kind} done"));
    true
}

/// Whether every active need of the node at `at` has a current part that is done.
fn needs_done(prog: &Program, root: &Node, at: &[usize]) -> bool {
    let n = node_at(root, at);
    prog.needs.iter().filter(|need| need.owner == n.kind).all(|need| {
        let active = need.cond.as_ref().is_none_or(|c| eval(prog, root, at, c) == T::Yes);
        !active || current(n, &need.part).is_some_and(|i| n.parts[i].status == Status::Done)
    })
}

/// Sends a ready part's request, unless a rule would break. Then the part
/// waits on that rule, and every later step of the unit checks it again
/// (appendix B.3.5).
fn request_pass(prog: &Program, u: &mut Unit, at: &[usize], asks: &mut Vec<Ask>) -> bool {
    let n = node_at(&u.root, at);
    let Some(effect) = prog.effect_of(&n.kind) else { return false };
    if n.status != Status::Idle || !needs_done(prog, &u.root, at) {
        return false;
    }
    let (kind, waiting) = (n.kind.clone(), n.waiting.clone());
    let mut t = u.root.clone();
    node_at_mut(&mut t, at).status = Status::Requested;
    match violated(prog, &t) {
        Some(r) if waiting.as_deref() == Some(r.name.as_str()) => false,
        Some(r) => {
            node_at_mut(&mut u.root, at).waiting = Some(r.name.clone());
            u.notes.push(format!("{kind} waits: rule {}", r.name));
            true
        }
        None => {
            node_at_mut(&mut t, at).waiting = None;
            u.root = t;
            let a = ask_for(&u.label, &u.root, at, effect);
            let sends: Vec<String> = a.sends.iter().map(|(k, v)| format!("{k} {}", v.show(&prog.currency))).collect();
            u.notes.push(format!("{kind} → {} via {} ({})", effect.verb, effect.adapter, sends.join(", ")));
            asks.push(a);
            true
        }
    }
}

/// Notes each goal of the root the first time it is met.
fn goals(prog: &Program, u: &mut Unit) {
    for (i, g) in prog.goals.iter().enumerate() {
        let i = i as u32;
        if g.kind != u.root.kind || u.met.contains(&i) {
            continue;
        }
        let applies = g.filter.iter().all(|f| eval(prog, &u.root, &[], f) == T::Yes);
        if applies && g.states.iter().all(|s| in_state(prog, &u.root, &[], s)) {
            u.met.push(i);
            u.notes.push(format!("goal met: {}", g.source));
        }
    }
}

/// Whether the node at `at` is in `state` (appendix B.3): `done`, `failed`, a
/// Bool attribute, its effect's marks or outcomes, or a defined state.
pub fn in_state(prog: &Program, root: &Node, at: &[usize], state: &str) -> bool {
    let n = node_at(root, at);
    match state {
        "done" => return n.status == Status::Done,
        "failed" => return n.status == Status::Failed,
        _ => {}
    }
    if let Some(Val::Bool(b)) = n.attrs.get(state) {
        return *b;
    }
    if let Some(e) = prog.effect_of(&n.kind) {
        if e.marks.as_deref() == Some(state) {
            return n.status != Status::Idle;
        }
        if e.success == state || e.failures.iter().any(|f| f == state) {
            return n.outcome.as_deref() == Some(state);
        }
    }
    prog.defines.iter().any(|d| d.kind == n.kind && d.state == state && eval(prog, root, at, &d.cond) == T::Yes)
}

/// The first rule the unit's state breaks, if any. A rule applies to a node
/// only when its filter is known to hold.
pub fn violated<'p>(prog: &'p Program, root: &Node) -> Option<&'p Rule> {
    let all = positions(root);
    prog.rules.iter().find(|r| {
        all.iter().any(|at| {
            node_at(root, at).kind == r.subject
                && r.filter.iter().all(|f| eval(prog, root, at, f) == T::Yes)
                && match &r.body {
                    Body::Every(c) => eval(prog, root, at, c) == T::No,
                    Body::No { pred, unless } => {
                        eval(prog, root, at, pred) == T::Yes && unless.as_ref().is_none_or(|u| eval(prog, root, at, u) != T::Yes)
                    }
                }
        })
    })
}

/// Three-valued truth. A value not given yet makes a comparison unknown
/// (appendix B.3.3).
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
enum T {
    Yes,
    No,
    Unknown,
}

fn truth(b: bool) -> T {
    if b { T::Yes } else { T::No }
}

fn eval(prog: &Program, root: &Node, at: &[usize], c: &Cond) -> T {
    match c {
        Cond::Cmp { left, op, right } => {
            let Some(l) = value(root, at, left) else { return T::Unknown };
            let r = match right {
                Operand::Lit(lit) => Val::from_lit(lit),
                Operand::Path(p) => match value(root, at, p) {
                    Some(v) => v.clone(),
                    None => return T::Unknown,
                },
            };
            compare(l, &r, *op).map_or(T::No, truth)
        }
        Cond::State { node, state, negated } => {
            let yes = locate(root, at, &node.steps).is_some_and(|n| in_state(prog, root, &n, state));
            truth(yes != *negated)
        }
        Cond::Has { node, part, state, negated } => {
            let exists = locate(root, at, &node.steps).is_some_and(|n| {
                node_at(root, &n).parts.iter().enumerate().any(|(i, p)| {
                    p.kind == *part && state.as_ref().is_none_or(|s| in_state(prog, root, &child(&n, i), s))
                })
            });
            truth(exists != *negated)
        }
        Cond::And(cs) => {
            let ts: Vec<T> = cs.iter().map(|c| eval(prog, root, at, c)).collect();
            if ts.contains(&T::No) {
                T::No
            } else if ts.contains(&T::Unknown) {
                T::Unknown
            } else {
                T::Yes
            }
        }
        Cond::Or(cs) => {
            let ts: Vec<T> = cs.iter().map(|c| eval(prog, root, at, c)).collect();
            if ts.contains(&T::Yes) {
                T::Yes
            } else if ts.contains(&T::Unknown) {
                T::Unknown
            } else {
                T::No
            }
        }
    }
}

/// Compares two values of the same type; `None` when the types differ.
fn compare(l: &Val, r: &Val, op: Op) -> Option<bool> {
    let ord = match (l, r) {
        (Val::Money(a), Val::Money(b)) | (Val::Count(a), Val::Count(b)) => a.cmp(b),
        (Val::Text(a), Val::Text(b)) => a.cmp(b),
        (Val::Bool(a), Val::Bool(b)) => a.cmp(b),
        _ => return None,
    };
    Some(match op {
        Op::Eq => ord.is_eq(),
        Op::Ne => ord.is_ne(),
        Op::Lt => ord.is_lt(),
        Op::Le => ord.is_le(),
        Op::Gt => ord.is_gt(),
        Op::Ge => ord.is_ge(),
    })
}

/// The node at a position: indexes into `parts`, starting at the root.
pub fn node_at<'a>(root: &'a Node, at: &[usize]) -> &'a Node {
    at.iter().fold(root, |n, &i| &n.parts[i])
}

fn node_at_mut<'a>(root: &'a mut Node, at: &[usize]) -> &'a mut Node {
    at.iter().fold(root, |n, &i| &mut n.parts[i])
}

/// Every position in the unit, owners before their parts.
fn positions(root: &Node) -> Vec<Vec<usize>> {
    fn walk(n: &Node, at: &mut Vec<usize>, out: &mut Vec<Vec<usize>>) {
        out.push(at.clone());
        for (i, p) in n.parts.iter().enumerate() {
            at.push(i);
            walk(p, at, out);
            at.pop();
        }
    }
    let mut out = vec![];
    walk(root, &mut vec![], &mut out);
    out
}

/// The current attempt of a part kind: the last one created.
fn current(n: &Node, kind: &str) -> Option<usize> {
    n.parts.iter().rposition(|p| p.kind == kind)
}

fn child(at: &[usize], i: usize) -> Vec<usize> {
    let mut pos = at.to_vec();
    pos.push(i);
    pos
}

/// Nothing in it has been requested from the outside world.
fn untouched(n: &Node) -> bool {
    n.status == Status::Idle && n.parts.iter().all(untouched)
}

/// Follows parts and owners. `None` if a part is missing, or the walk goes above the root.
fn locate(root: &Node, from: &[usize], steps: &[Step]) -> Option<Vec<usize>> {
    let mut at = from.to_vec();
    for s in steps {
        match s {
            Step::Owner => {
                at.pop()?;
            }
            Step::Part(k) => {
                let i = current(node_at(root, &at), k)?;
                at.push(i);
            }
            Step::Attr(_) => return None,
        }
    }
    Some(at)
}

/// The value a path ends at, if it has one yet.
fn value<'a>(root: &'a Node, from: &[usize], path: &Path) -> Option<&'a Val> {
    let (last, rest) = path.steps.split_last()?;
    let Step::Attr(name) = last else { return None };
    node_at(root, &locate(root, from, rest)?).attrs.get(name)
}

fn ask_for(label: &str, root: &Node, at: &[usize], e: &Effect) -> Ask {
    let sends = e.sends.iter().filter_map(|(name, path)| value(root, at, path).map(|v| (name.clone(), v.clone()))).collect();
    Ask {
        adapter: e.adapter.clone(),
        verb: e.verb.clone(),
        kind: e.kind.clone(),
        label: label.to_string(),
        key: request_key(label, root, at),
        sends,
    }
}

/// `O1/CustomsForm/Declaration#1`: the unit, the kinds from the root down to
/// the part, and its attempt.
pub fn request_key(label: &str, root: &Node, at: &[usize]) -> String {
    let mut kinds = vec![];
    let mut n = root;
    for &i in at {
        n = &n.parts[i];
        kinds.push(n.kind.as_str());
    }
    format!("{label}/{}#{}", kinds.join("/"), n.attempt)
}
```

```rust
//! The kernel program that every compiled Suture program runs on (spec
//! appendix B.3.1): one unit agent per root entity, messages queued at its
//! mailbox, outside requests as effects, and three generic rules.

use std::sync::Arc;

use suture::{DigestBuilder, KindId, PatchView, Policy, Program as KernelProgram, RuleTable, SigBuilder, ValueType};
use suture_lang::ir::Program;

use crate::interp;
use crate::state::{answer_from_value, send_from_value, send_value, Ask, Msg, Unit};

/// The runtime's kernel kinds.
#[derive(Clone, Copy, Debug)]
pub struct Kinds {
    /// A unit, waiting at its mailbox.
    pub unit: KindId,
    /// A message, queued at a mailbox.
    pub msg: KindId,
    /// An outside request: an effect whose hole the adapter's answer fills.
    pub ask: KindId,
    /// An adapter's answer, injected at an `Ask`'s hole.
    pub answer: KindId,
    /// An internal message for a mailbox: an effect that the host routes.
    pub send: KindId,
    /// The host's routing agent, which joins a `Send` to a mailbox.
    pub deliver: KindId,
}

/// The kernel program for a compiled program. Its fingerprint pins the
/// compiled program's hash (plan 1), so a journal replays only under the
/// same program.
pub fn program(prog: Arc<Program>) -> (KernelProgram, Kinds) {
    let mut b = SigBuilder::new(&format!("suture:{}", prog.module), prog.version);
    let (mailbox, reply, route) = (b.polarized("Mailbox"), b.polarized("Reply"), b.polarized("Route"));
    let k = Kinds {
        unit: b.kind("Unit", mailbox.neg()).payload(ValueType::Any).done(),
        msg: b.kind("Msg", mailbox.pos()).aux("rest", mailbox.neg()).payload(ValueType::Any).done(),
        ask: b.kind("Ask", reply.neg()).payload(ValueType::Any).effect().done(),
        answer: b.kind("Answer", reply.pos()).payload(ValueType::Any).done(),
        send: b.kind("Send", route.neg()).payload(ValueType::Any).effect().done(),
        deliver: b.kind("Deliver", route.pos()).aux("to", mailbox.pos()).aux("next", mailbox.neg()).done(),
    };
    let sig = b.build().expect("the runtime signature is valid");
    let mut t = RuleTable::new();
    let p = prog.clone();
    t.def("step", k.msg, k.unit, move |cx| {
        let [rest] = cx.left_aux();
        let msg = Msg::from_value(cx.left()).map_err(|e| cx.reject(e))?;
        let unit = Unit::from_value(cx.right()).map_err(|e| cx.reject(e))?;
        let out = interp::step(&p, &unit, &msg);
        cx.agent(k.unit, out.unit.to_value(), rest, &[]);
        for a in &out.asks {
            cx.effect(k.ask, a.to_value(), &[]);
        }
        Ok(())
    })
    .emits(&[k.ask]);
    t.def("answer", k.answer, k.ask, move |cx| {
        let ask = Ask::from_value(cx.right()).map_err(|e| cx.reject(e))?;
        let (outcome, data) = answer_from_value(cx.left()).map_err(|e| cx.reject(e))?;
        let msg = Msg::Answer { key: ask.key.clone(), outcome, data };
        cx.effect(k.send, send_value(&ask.label, &msg), &[]);
        Ok(())
    })
    .emits(&[k.send]);
    t.def("deliver", k.deliver, k.send, move |cx| {
        let [to, next] = cx.left_aux();
        let (_, msg) = send_from_value(cx.right()).map_err(|e| cx.reject(e))?;
        cx.agent(k.msg, msg, to, &[next]);
        Ok(())
    });
    let hash = {
        let mut d = DigestBuilder::new("suture-program");
        d.str(&serde_json::to_string(&*prog).expect("compiled programs serialize"));
        d.finish()
    };
    let kernel = KernelProgram::new(sig, t)
        .expect("the runtime rules are valid")
        .with_policy(RulesHold { prog, unit: k.unit })
        .with_fingerprint(hash);
    (kernel, k)
}

/// The safety net of spec D8: whatever the interpreter computes, a unit
/// state that breaks a rule is never installed.
struct RulesHold {
    prog: Arc<Program>,
    unit: KindId,
}

impl Policy for RulesHold {
    fn name(&self) -> &str {
        "rules-hold"
    }

    fn check(&self, view: &PatchView<'_>) -> Result<(), String> {
        for payload in view.created_of(self.unit) {
            let unit = Unit::from_value(payload)?;
            if let Some(r) = interp::violated(&self.prog, &unit.root) {
                return Err(format!("rule {} would break", r.name));
            }
        }
        Ok(())
    }
}
```

- [ ] **Step 4: Write the host loop.** Write `runtime/src/host.rs`:

```rust
//! The host loop (spec §5.4, as corrected by appendix B.3.6). It runs the
//! kernel, routes internal messages, commits, and only then hands outside
//! requests to adapters. In slice 1 the adapters are simulated: a scenario
//! answers for them, one request at a time.

use std::sync::Arc;

use suture::{HoleId, Injection, Machine, NetBuilder, Value};
use suture_lang::ir::Program;

use crate::interp;
use crate::kernel::{self, Kinds};
use crate::state::{answer_value, send_from_value, Ask, Msg, Unit, Val};

pub struct Host {
    pub prog: Arc<Program>,
    pub machine: Machine,
    pub kinds: Kinds,
    /// One line for each thing that happened: each unit's notes, and each answer.
    pub trace: Vec<String>,
    /// Outside requests waiting for an answer, oldest first, with their effect holes.
    pending: Vec<(Ask, HoleId)>,
}

impl Host {
    pub fn new(prog: Program) -> Host {
        let prog = Arc::new(prog);
        let (kernel, kinds) = kernel::program(prog.clone());
        Host { prog, machine: Machine::new(kernel), kinds, trace: vec![], pending: vec![] }
    }

    /// Creates a root entity as a new unit labeled `label`, and settles it.
    pub fn create(&mut self, kind: &str, label: &str, given: &[(String, Val)]) -> Result<(), String> {
        if self.machine.hole(label).is_some() {
            return Err(format!("{label} already exists"));
        }
        let unit = interp::new_unit(&self.prog, label, kind, given)?;
        let sig = self.machine.program().sig.clone();
        let mut b = NetBuilder::new(&sig);
        let (meet, rest) = (b.var(), b.var());
        b.agent(self.kinds.unit, unit.to_value(), meet, &[]);
        b.agent(self.kinds.msg, Msg::Create.to_value(), meet, &[rest]);
        let net = b.finish().map_err(|e| e.to_string())?;
        self.machine.inject(Injection::new(net).new_hole(rest, Some(label))).map_err(|e| e.to_string())?;
        self.machine.run(None);
        self.note(label)?;
        self.pump()
    }

    /// The adapter answers its oldest pending request, or the oldest for `target`.
    pub fn answer(&mut self, adapter: &str, outcome: &str, data: &[(String, Val)], target: Option<&str>) -> Result<(), String> {
        let i = self
            .pending
            .iter()
            .position(|(a, _)| a.adapter == adapter && target.is_none_or(|t| a.label == t))
            .ok_or_else(|| format!("{adapter} has no pending request{}", target.map(|t| format!(" for {t}")).unwrap_or_default()))?;
        let (ask, hole) = self.pending.remove(i);
        let shown: Vec<String> = data.iter().map(|(k, v)| format!("{k} {}", v.show(&self.prog.currency))).collect();
        let tail = if shown.is_empty() { String::new() } else { format!(", {}", shown.join(", ")) };
        self.trace.push(format!("      {adapter}: {outcome}{tail}   ({})", ask.key));
        let sig = self.machine.program().sig.clone();
        let mut b = NetBuilder::new(&sig);
        let meet = b.var();
        b.agent(self.kinds.answer, answer_value(outcome, data), meet, &[]);
        let net = b.finish().map_err(|e| e.to_string())?;
        let inj = Injection::new(net).at_hole(meet, hole).key(format!("answer:{:032x}", hole.0));
        self.machine.inject(inj).map_err(|e| e.to_string())?;
        self.pump()
    }

    /// A unit's current state, read from the graph.
    pub fn unit(&self, label: &str) -> Option<Unit> {
        let h = self.machine.hole(label)?;
        let (_, port, agent) = self.machine.hole_peer(h)?;
        if agent.kind != self.kinds.unit || port != 0 {
            return None;
        }
        Unit::from_value(&agent.payload).ok()
    }

    /// The outside requests still waiting for an answer, oldest first.
    pub fn pending(&self) -> Vec<&Ask> {
        self.pending.iter().map(|(a, _)| a).collect()
    }

    /// Runs until nothing is left to do. Internal messages are routed as they
    /// appear. Then the journal is committed, and only after that are new
    /// outside requests handed to adapters (`ir-spec.md` §8.2).
    fn pump(&mut self) -> Result<(), String> {
        loop {
            self.machine.run(None);
            let effects = self.machine.take_new_effects();
            let mut outside = vec![];
            for e in &effects {
                if e.kind == self.kinds.send {
                    self.route(e.hole, &e.payload)?;
                } else if e.kind == self.kinds.ask {
                    outside.push((Ask::from_value(&e.payload)?, e.hole));
                }
            }
            self.machine.commit().map_err(|e| e.to_string())?;
            self.pending.extend(outside);
            if effects.is_empty() {
                return Ok(());
            }
        }
    }

    /// Delivers an internal message to its unit's mailbox, and notes what the unit did.
    fn route(&mut self, hole: HoleId, payload: &Value) -> Result<(), String> {
        let (label, _) = send_from_value(payload)?;
        let sig = self.machine.program().sig.clone();
        let mut b = NetBuilder::new(&sig);
        let (meet, to, next) = (b.var(), b.var(), b.var());
        b.agent(self.kinds.deliver, (), meet, &[to, next]);
        let net = b.finish().map_err(|e| e.to_string())?;
        let inj = Injection::new(net).at_hole(meet, hole).at_label(to, &label).new_hole(next, Some(&label));
        self.machine.inject(inj).map_err(|e| e.to_string())?;
        self.machine.run(None);
        self.note(&label)
    }

    /// Adds the unit's notes from its last step to the trace.
    fn note(&mut self, label: &str) -> Result<(), String> {
        let Some(unit) = self.unit(label) else {
            let faults: Vec<String> = self.machine.faults().into_iter().map(|f| f.error).collect();
            return Err(format!("{label}: a step faulted: {}", faults.join("; ")));
        };
        for n in &unit.notes {
            self.trace.push(format!("{label:<4}{n}"));
        }
        Ok(())
    }
}
```

```rust
//! Scenarios (spec §7.1, appendix B.2): `when a new …`, `… answers …` and
//! `expect …`, one per indented line under `scenario "title":`.

use crate::ast::Literal;
use crate::lex::{statements, Cursor, Error, Tok};
use crate::sentence::literal;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Scenario {
    pub title: String,
    pub steps: Vec<ScenarioStep>,
    pub line: usize,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum ScenarioStep {
    /// `when a new Order O1 with country France and total 120 EUR`
    Create { kind: String, name: String, attrs: Vec<(String, Literal)> },
    /// `and forms answers filled with licence "L-77" [for O1]`
    Answer { adapter: String, outcome: String, data: Vec<(String, Literal)>, target: Option<String> },
    /// `expect O1 is [not] settled`
    Expect { name: String, state: String, negated: bool },
}

pub fn parse_scenarios(file: &str, src: &str) -> Result<Vec<Scenario>, Error> {
    let mut out = vec![];
    for st in statements(file, src)? {
        let mut c = Cursor::new(&st.lines[0], &st.file, st.line);
        c.expect_word("scenario")?;
        let title = match c.peek() {
            Some(Tok::Str(s)) => s.clone(),
            _ => return Err(c.error(format!("expected the scenario's title in quotes, found {}", c.found()))),
        };
        c.next();
        c.expect_sym(':')?;
        c.expect_end()?;
        let mut steps = vec![];
        for line in &st.lines[1..] {
            let mut c = Cursor::new(line, &st.file, st.line);
            steps.push(step(&mut c)?);
            c.expect_end()?;
        }
        out.push(Scenario { title, steps, line: st.line });
    }
    Ok(out)
}

fn step(c: &mut Cursor) -> Result<ScenarioStep, Error> {
    if c.eat_word("expect") {
        let name = c.word()?;
        c.expect_word("is")?;
        let negated = c.eat_word("not");
        return Ok(ScenarioStep::Expect { name, state: c.word()?, negated });
    }
    if !(c.eat_word("when") || c.eat_word("and")) {
        return Err(c.error(format!("expected `when`, `and` or `expect`, found {}", c.found())));
    }
    if c.eat_word("a") || c.eat_word("an") {
        c.expect_word("new")?;
        let kind = c.kind_name()?;
        let name = c.word()?;
        let attrs = if c.eat_word("with") { pairs(c)? } else { vec![] };
        return Ok(ScenarioStep::Create { kind, name, attrs });
    }
    let adapter = c.word()?;
    c.expect_word("answers")?;
    let outcome = c.word()?;
    let data = if c.eat_word("with") { pairs(c)? } else { vec![] };
    let target = if c.eat_word("for") { Some(c.word()?) } else { None };
    Ok(ScenarioStep::Answer { adapter, outcome, data, target })
}

/// `a 1, b "x" and c 3 EUR`. A bare word is text.
fn pairs(c: &mut Cursor) -> Result<Vec<(String, Literal)>, Error> {
    let mut out = vec![];
    loop {
        let name = c.word()?;
        let value = match literal(c)? {
            Some(l) => l,
            None => Literal::Text(c.word()?),
        };
        out.push((name, value));
        if !(c.eat_sym(',') || c.eat_word("and")) {
            return Ok(out);
        }
    }
}
```

```rust
//! Running a scenario against simulated adapters (spec §7.1, appendix B.1).

use suture_lang::ast::Literal;
use suture_lang::ir::Program;
use suture_lang::scenario::{Scenario, ScenarioStep};

use crate::host::Host;
use crate::interp::in_state;
use crate::state::Val;

/// What a scenario did: its host, with the trace, and the steps that failed.
pub struct Report {
    pub title: String,
    pub host: Host,
    pub failures: Vec<String>,
}

impl Report {
    pub fn passed(&self) -> bool {
        self.failures.is_empty()
    }
}

/// Runs every step in order. A step that cannot apply fails the report, and
/// the run continues with the next step.
pub fn run(prog: &Program, sc: &Scenario) -> Report {
    let mut host = Host::new(prog.clone());
    let mut failures = vec![];
    for (i, step) in sc.steps.iter().enumerate() {
        let result = match step {
            ScenarioStep::Create { kind, name, attrs } => values(prog, attrs).and_then(|v| host.create(kind, name, &v)),
            ScenarioStep::Answer { adapter, outcome, data, target } => {
                values(prog, data).and_then(|v| host.answer(adapter, outcome, &v, target.as_deref()))
            }
            ScenarioStep::Expect { name, state, negated } => {
                let r = expect(&host, name, state, *negated);
                let mark = if r.is_ok() { "✓" } else { "✗" };
                host.trace.push(format!("{mark} expect {name} is {}{state}", if *negated { "not " } else { "" }));
                r
            }
        };
        if let Err(e) = result {
            failures.push(format!("step {}: {e}", i + 1));
        }
    }
    Report { title: sc.title.clone(), host, failures }
}

fn values(prog: &Program, pairs: &[(String, Literal)]) -> Result<Vec<(String, Val)>, String> {
    pairs
        .iter()
        .map(|(k, l)| {
            let v = match l {
                Literal::Text(s) => Val::Text(s.clone()),
                Literal::Bool(b) => Val::Bool(*b),
                Literal::Count(n) => Val::Count(*n),
                Literal::Money { cents, currency } if *currency == prog.currency => Val::Money(*cents),
                Literal::Money { currency, .. } => {
                    return Err(format!("{k}: an amount in {currency} is not in this module's currency, {}", prog.currency));
                }
            };
            Ok((k.clone(), v))
        })
        .collect()
}

fn expect(host: &Host, name: &str, state: &str, negated: bool) -> Result<(), String> {
    let unit = host.unit(name).ok_or_else(|| format!("there is no unit {name}"))?;
    if in_state(&host.prog, &unit.root, &[], state) == negated {
        return Err(format!("expected {name} is {}{state}", if negated { "not " } else { "" }));
    }
    Ok(())
}
```

```rust
//! Explanations (spec §5.6): why a unit is where it is, read from its state.

use suture_lang::ir::Program;

use crate::interp::{holds, in_state};
use crate::state::{Node, Status, Unit};

/// One line for the unit, one per goal, and one per part, indented by depth.
pub fn explain(prog: &Program, unit: &Unit) -> Vec<String> {
    let attrs: Vec<String> = unit.root.attrs.iter().map(|(k, v)| format!("{k} {}", v.show(&prog.currency))).collect();
    let mut out = vec![format!("{} {} ({})", unit.root.kind, unit.label, attrs.join(", "))];
    for g in prog.goals.iter().filter(|g| g.kind == unit.root.kind) {
        if !g.filter.iter().all(|f| holds(prog, &unit.root, &[], f)) {
            out.push(format!("  goal does not apply: {}", g.source));
            continue;
        }
        let missing: Vec<&str> = g.states.iter().filter(|s| !in_state(prog, &unit.root, &[], s)).map(String::as_str).collect();
        out.push(if missing.is_empty() {
            format!("  goal met: {}", g.source)
        } else {
            format!("  goal not met yet: {} (not yet {})", g.source, missing.join(", "))
        });
    }
    for p in &unit.root.parts {
        part(prog, p, 1, &mut out);
    }
    out
}

fn part(prog: &Program, n: &Node, depth: usize, out: &mut Vec<String>) {
    let effect = prog.effect_of(&n.kind);
    let what = match (n.status, &n.waiting) {
        (Status::Idle, Some(rule)) => format!("waiting: rule {rule}"),
        (Status::Idle, None) if effect.is_some() => "not requested yet".to_string(),
        (Status::Idle, None) => "waiting for its parts".to_string(),
        (Status::Requested, _) => format!("requested from {}", effect.map_or("?", |e| e.adapter.as_str())),
        (Status::Done, _) => n.outcome.clone().unwrap_or_else(|| "done".to_string()),
        (Status::Failed, _) => format!("failed ({})", n.outcome.as_deref().unwrap_or("?")),
    };
    let attempt = if n.attempt > 1 { format!(" (attempt {})", n.attempt) } else { String::new() };
    let attrs: Vec<String> = n.attrs.iter().map(|(k, v)| format!("{k} {}", v.show(&prog.currency))).collect();
    let attrs = if attrs.is_empty() { String::new() } else { format!(" — {}", attrs.join(", ")) };
    out.push(format!("{}{}{attempt}: {what}{attrs}", "  ".repeat(depth), n.kind));
    for p in &n.parts {
        part(prog, p, depth + 1, out);
    }
}
```

```rust
//! The `suture` command (spec appendix B.1):
//!
//! - `suture build <dir>`
//! - `suture run <dir> --scenario <file>`
//! - `suture explain <dir> --scenario <file> <name>`

use std::path::Path;
use std::process::ExitCode;

use suture_lang::ir::Program;

const USAGE: &str =
    "usage:\n  suture build <dir>\n  suture run <dir> --scenario <file>\n  suture explain <dir> --scenario <file> <name>";

fn main() -> ExitCode {
    let args: Vec<String> = std::env::args().skip(1).collect();
    let args: Vec<&str> = args.iter().map(String::as_str).collect();
    let result = match args.as_slice() {
        ["build", dir] => build(Path::new(dir)),
        ["run", dir, "--scenario", file] => scenarios(Path::new(dir), Path::new(file), None),
        ["explain", dir, "--scenario", file, name] => scenarios(Path::new(dir), Path::new(file), Some(*name)),
        _ => Err(USAGE.to_string()),
    };
    match result {
        Ok(true) => ExitCode::SUCCESS,
        Ok(false) => ExitCode::FAILURE,
        Err(msg) => {
            eprintln!("{msg}");
            ExitCode::from(2)
        }
    }
}

fn compile(dir: &Path) -> Result<Program, String> {
    suture_lang::compile_dir(dir).map_err(|errors| errors.iter().map(|e| e.to_string()).collect::<Vec<_>>().join("\n"))
}

/// Compiles, writes the program file, and prints every rule's read-back.
fn build(dir: &Path) -> Result<bool, String> {
    let prog = compile(dir)?;
    let out = dir.join(format!("{}-v{}.sut", prog.module, prog.version));
    let json = serde_json::to_string_pretty(&prog).map_err(|e| e.to_string())?;
    std::fs::write(&out, json).map_err(|e| format!("{}: {e}", out.display()))?;
    println!("{} v{} → {}", prog.module, prog.version, out.display());
    println!(
        "  kinds {} · effects {} · rules {} · goals {}",
        prog.kinds.len(),
        prog.effects.len(),
        prog.rules.len(),
        prog.goals.len()
    );
    for r in &prog.rules {
        println!("\nrule {}: {}", r.name, r.source);
        println!("  understood as:   {}", r.formula);
        println!("  in other words:  {}", r.paraphrase);
        println!("  cost:            {}", r.tier);
    }
    Ok(true)
}

/// Runs every scenario in `file` and prints its trace. With `explain`, it
/// also explains that unit at the end of each scenario that has it.
fn scenarios(dir: &Path, file: &Path, explain: Option<&str>) -> Result<bool, String> {
    let prog = compile(dir)?;
    let src = std::fs::read_to_string(file).map_err(|e| format!("{}: {e}", file.display()))?;
    let list = suture_lang::scenario::parse_scenarios(&file.display().to_string(), &src).map_err(|e| e.to_string())?;
    let mut all_passed = true;
    for sc in &list {
        let report = suture_runtime::scenario::run(&prog, sc);
        println!("scenario \"{}\"", report.title);
        for line in &report.host.trace {
            println!("  {line}");
        }
        if let Some(unit) = explain.and_then(|name| report.host.unit(name)) {
            println!();
            for line in suture_runtime::explain::explain(&prog, &unit) {
                println!("  {line}");
            }
        }
        for f in &report.failures {
            println!("  ✗ {f}");
        }
        println!("  {}\n", if report.passed() { "passed" } else { "FAILED" });
        all_passed &= report.passed();
    }
    Ok(all_passed)
}
```
